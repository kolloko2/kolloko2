# МАГНАТ: Империя — прототип (этап 0)

Экономическая стратегия на реальной карте мира: открывайте кофейни, пекарни, фастфуд и магазины в 26 городах,
стройте свои обжарки, мельницы, фермы и плантации, которые снабжают ваши точки.
Пока без 3D: своя стилизованная карта мира (Leaflet + данные Natural Earth), иконки и панели.

## Запуск

```bash
cd game
npm start          # открыть http://localhost:8080
```

Нужен только Node.js 22+, устанавливать пакеты не надо. Интернет не нужен: карта и иконки лежат в проекте.

## Мультиплеер

`npm start` запускает и сервер игры. В меню выберите режим:

- **Одиночная** — вы против ИИ, сохранение в браузере.
- **Кооператив** — одна общая компания на всех, каждый может управлять любым бизнесом.
- **Против друзей** — у каждого своя компания в одном мире: конкуренция за районы и покупателей,
  можно выкупить помещение соперника и получать с него аренду. Скорость времени — минимальная из голосов.
- **Войти по коду** — друг открывает тот же адрес (например, `http://<ваш-ip>:8080`) и вводит 5-значный код комнаты.

Комнаты сохраняются в `server-data/rooms/`, вернуться можно по коду даже после перезапуска сервера.
Для игры через интернет сервер нужно выложить на хостинг (или пробросить порт / использовать туннель вроде ngrok).

```bash
npm test           # тесты симуляции и сервера
npm run headless   # бот играет 5 лет без интерфейса — для проверки баланса
```

## Устройство

- `src/data/` — все числа баланса: города, районы, товары, бизнесы.
- `src/sim/` — ядро экономики без DOM (работает и в браузере, и на сервере). Мир с несколькими компаниями;
  все действия — команды `applyCommand(state, cmd, companyId)`, ГСЧ детерминированный.
- `src/net/` — сессии: `LocalSession` (соло, симуляция в браузере) и `RemoteSession` (мультиплеер),
  снимки состояния для сети. Интерфейс работает с любой сессией одинаково.
- `server/` — HTTP-сервер, WebSocket без зависимостей, комнаты с авторитетной симуляцией.
- `src/ui/` — карта, панели, вкладки.
- `vendor/leaflet/` — библиотека карты Leaflet 1.9.4 (BSD-2-Clause).
- `assets/map/` — страны, озёра и реки из Natural Earth (public domain), упрощённые скриптом `tools/map/build_map.py`;
  он же строит `src/data/landmask.js` — маску суши, чтобы районы и участки не попадали в воду.
- `src/ui/basemap.js` — отрисовка своей карты: пастельные страны, гранёная текстура, процедурные кварталы в городах.
