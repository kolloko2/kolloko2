# 08. Конкуренция, торговля и переговоры

## 8.1 ИИ-конкуренты

### 8.1.1 Уровни ИИ
1. **Фоновые бизнесы** — тысячи мелких точек, моделируемых агрегированно как «плотность конкуренции» в районе. Открываются/закрываются по рентабельности ниши. Обеспечивают живость мира.
2. **ИИ-корпорации** (40–200) — полноценные агенты с компаниями, брендами, цепочками, акциями на бирже. Имеют **архетип** и **характер**.
3. **ИИ-магнаты** (5–10 в сессии, опционально) — «боссы» с именами и биографиями, играющие по тем же правилам, что игрок (для соло-режима это основные соперники).

### 8.1.2 Архетипы ИИ-корпораций
| Архетип | Поведение | Пример |
|---|---|---|
| **Дискаунтер** | Низкие цены, экономия на всём, агрессивная экспансия в спальные районы | «ЭконоМарт» |
| **Премиум-бренд** | Высокое качество, медленный рост, огромный маркетинг | «Maison Lumière» |
| **Вертикальный интегратор** | Скупает поставщиков, контролирует цепочку | «AgroUnited» |
| **Консолидатор** | Покупает слабых конкурентов (в т.ч. игроков в беде) | «Titan Holdings» |
| **Инноватор** | Ставка на R&D, первым выводит технологии | «NovaTech» |
| **Государственный чемпион** | Госкомпания: поддержка государства, лицензии, неэффективность | «НацНефть» |
| **Рейдер/спекулянт** | Враждебные поглощения, шорты, распродажа активов | «Vulture Capital» |
| **Картельщик** | Предлагает ценовые сговоры игрокам | «Consortio» |

### 8.1.3 Характер (параметры личности ИИ)
`агрессивность, склонность к риску, честность (соблюдение договоров), мстительность, кооперативность, терпение` — влияют на переговоры и реакции. ИИ помнит действия игрока (**отношения −100..+100**): тот, кого игрок обманул, не заключит контракт или отомстит ценовой войной.

### 8.1.4 Реакции ИИ на действия игрока
- Игрок открылся рядом → ИИ может: снизить цены, запустить рекламу, улучшить качество, предложить «раздел рынка», или уйти.
- Игрок захватил > 30% рынка → ИИ-консолидаторы объединяются, ИИ лоббирует антимонопольное расследование.
- Игрок в долгах → ИИ-рейдеры скупают его облигации / предлагают купить активы дёшево.

## 8.2 Механики конкуренции

### 8.2.1 Ценовые войны
- Снижение цен ниже себестоимости для вытеснения конкурента — у кого больше «запас прочности» (кэш, кредитная линия, диверсификация), тот выигрывает.
- **Демпинг** может быть наказан регулятором (при доле рынка > 35% и цене < себестоимости — расследование).
- В PvP — классическая борьба кошельков; кооп-союзники могут субсидировать друг друга.

### 8.2.2 Борьба за локации
- Скупка лучших участков (первая линия, углы) раньше конкурента.
- Покупка здания, где арендует соперник, → отказ в продлении аренды.

### 8.2.3 Борьба за поставщиков и каналы
- **Эксклюзивные контракты:** обжарка продаёт зерно только вам.
- Скупка поставщика соперника (вертикальная интеграция как оружие).
- **Блокировка канала сбыта:** сеть супермаркетов игрока отказывается брать продукцию фабрики соперника (или требует бонус за полку).

### 8.2.4 Борьба за кадры
- Хедхантинг звёздных сотрудников соперника.
- Повышение зарплат в городе, чтобы задушить ФОТ соперника (дорого для обоих).
- Неконкурентные соглашения (non-compete) — дорогое условие найма, защищающее от хедхантинга.

### 8.2.5 Информационная война
- **Маркетинговые исследования** (легально): объёмы, доли, цены.
- **Промышленный шпионаж** (нелегально, опционально — отключаемо в настройках лобби): кража технологий, контрактов, планов. Шанс провала → скандал, штраф, суд.
- **Кибератаки** (опционально): требуют IT; защита — антивирус/кибербезопасность.
- **Медиакампании** (через медиа).

### 8.2.6 Саботаж (только при включённом «Жёстком режиме» в лобби)
- Подкуп инспекторов (санинспекция у соперника), организация забастовки, «утечка» компромата.
- Высокий риск: при раскрытии — уголовное дело против компании (огромный штраф, потеря лицензий, отставка CEO).
- Защита: охранное агентство, юристы, служба безопасности (внутренний отдел).

## 8.3 Торговля между игроками

### 8.3.1 Что можно торговать
- Товары (разовые сделки и контракты).
- Услуги (логистика, реклама, ПО, строительство, кредиты).
- Активы: бизнес-юниты, участки, здания, ресурсные лицензии, патенты/лицензии на технологии, бренды.
- Акции, облигации, доли в компаниях.
- Деньги (займы между игроками с процентами).
- **Обещания** (неформальные, не исполнимые кодом: «не открою кофейни в Берлине» — доверие и репутация игрока).

### 8.3.2 Типы контрактов (исполнимые кодом)

| Шаблон | Ключевые поля |
|---|---|
| **Поставка** | Товар, объём/период, мин. качество, цена (фикс / индекс к споту ± %), срок, пункт доставки, кто платит логистику (Incoterms-упрощённо: «самовывоз» / «доставка»), штраф за недопоставку, штраф за отказ от приёмки |
| **Эксклюзив** | «Покупатель обязуется покупать только у Продавца» и/или «Продавец продаёт только Покупателю» в регионе X |
| **Take-or-pay** | Покупатель платит за минимальный объём даже если не забрал (гарантия для инвестиций продавца) |
| **Услуга** | Логистика / реклама / ПО / строительство: объём, SLA, цена |
| **Заём** | Сумма, ставка, срок, залог (актив), ковенанты |
| **Аренда** | Участок/здание/оборудование/судно: срок, ставка, индексация |
| **Лицензия** | Технология/бренд: роялти %, территория, срок |
| **Франшиза** | Бренд + стандарты + закупки у франчайзера, роялти |
| **Опцион** | Право купить/продать актив по цене X до даты Y |
| **Совместное предприятие** | Доли, вклады, распределение прибыли, правила выхода |
| **Неконкуренция** | «Сторона А не открывает бизнесы типа T в регионе R до даты D» — штраф за нарушение (исполняется: система блокирует открытие или автоматически списывает штраф) |
| **Картельное соглашение** | Квоты добычи/выпуска, ценовой коридор (⚠ нелегально в большинстве стран — риск антимонопольного расследования; ОПЕК-подобное межгосударственное — легально для нефти) |

### 8.3.3 Исполнение
- Контракты исполняются автоматически системой: поставки идут, деньги списываются.
- При невозможности исполнения (нет товара, нет денег) → штраф по договору, удар по **деловой репутации** игрока (видна всем), запись в «историю контрагента».
- Спор → **арбитраж** (автоматический по условиям) или суд (событие, длительность, издержки).
- Досрочное расторжение — по условиям (штраф за выход).

### 8.3.4 Деловая репутация игрока
Публичный показатель `0–100` + история: выполненные/нарушенные контракты, просрочки, суды. ИИ учитывает её при сделках; игроки видят её при переговорах.

## 8.4 Переговоры

### 8.4.1 Интерфейс переговоров между игроками
- **Окно сделки** (в стиле trade-окна стратегий): две колонки «Я даю / Я получаю», drag-and-drop активов, конструктор условий контракта.
- **Предложение → контрпредложение → … → принять / отклонить / истечь по таймеру.**
- Чат и голос (опционально через WebRTC) внутри переговоров.
- **Подсказка «оценка сделки»**: система показывает справедливую оценку каждой позиции по своей модели (можно отключить в лобби для хардкора).

### 8.4.2 Переговоры с ИИ
Мини-игра торга:
- У ИИ есть скрытая **цена резервации** (BATNA) и **характер**.
- Игрок делает предложение; ИИ отвечает контрпредложением, сигналами («это оскорбительно», «близко»), может уйти.
- Факторы: репутация игрока, отношения, навык переговорщика (именной сотрудник), информация (разведка раскрывает BATNA приблизительно), альтернативы ИИ (сколько ещё покупателей).
- Тактики: якорение, пакетные сделки («возьму больше объём за скидку»), ультиматум, отсрочка, привязка к индексу.

### 8.4.3 Аукционы
| Аукцион | Где используется | Формат |
|---|---|---|
| Государственные лицензии (нефтяные блоки, частоты связи, слоты аэропортов) | Государство | Закрытые ставки (sealed-bid, first-price) или английский |
| Участки в городе | Город/ИИ | Английский (открытый, на повышение) |
| Активы банкротов | Суд | Голландский (на понижение) — драматично в PvP |
| Госзаказы (строительство дорог, лекарства, униформа армии) | Государство | Тендер на понижение цены + критерии качества |
| Произведения искусства/престиж | Аукционный дом | Английский |

## 8.5 Союзы, картели и дипломатия игроков

- **Альянс** (формальный статус в PvP): видимость части данных друг друга, льготные контракты, общие цели. Разрыв альянса — публичное событие.
- **Картель:** соглашение о ценах/квотах. Механика «дилеммы заключённого»: каждый участник может тайно нарушить квоту для выгоды; нарушение раскрывается с задержкой по рыночной статистике.
- **Раздел рынков:** «ты — Европа, я — Азия» как контракт неконкуренции.
- **Предательство** — легальная механика PvP: можно выйти из альянса, перекупить поставщика союзника, шортить его акции. Последствия — только репутационные (и месть).
