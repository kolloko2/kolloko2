# 03. Экономическая модель

Экономика — сердце игры. Цель: **агентная модель с рыночным клирингом**, достаточно глубокая для реалистичного поведения, но вычисляемая в браузере/на сервере для 8 игроков + 40–200 ИИ-компаний + ~250 городов.

## 3.1 Участники экономики

| Агент | Количество | Роль |
|---|---|---|
| **Домохозяйства** | Агрегировано: 5 квинтилей дохода × каждый город | Потребляют B2C-товары/услуги, работают, сберегают |
| **Фирмы игроков** | Неограниченно | Производят, покупают, продают |
| **ИИ-фирмы** | 40–200 корпораций + тысячи «фоновых» мелких бизнесов (агрегировано) | Конкурируют, поставляют, покупают |
| **Государства** | ≈60 + агрегированный «остальной мир» | Налоги, госзаказы, законы, ЦБ |
| **Внешний мир** | 1 агент | Бесконечный, но дорогой источник/сток товаров (импорт/экспорт по мировой цене + наценка). Не даёт рынкам «умереть» |
| **Банки ИИ** | По 2–5 на страну | Кредитование, депозиты |

## 3.2 Товары и услуги

Всего ~150 товаров в 8 категориях (полный список — глава 05):
1. **Сырьё** (нефть, газ, руда, зерно, кофе-зерно, древесина, хлопок, …)
2. **Полуфабрикаты** (сталь, пластик, бензин, мука, ткань, кремниевые пластины, …)
3. **Компоненты** (чипы, двигатели, аккумуляторы, экраны, …)
4. **Потребительские товары** (продукты, одежда, электроника, автомобили, лекарства, …)
5. **Услуги B2C** (питание, стрижки, фитнес, медицина, жильё, связь, развлечения, …)
6. **Услуги B2B** (логистика, реклама, ПО, консалтинг, охрана, клининг, строительство, …)
7. **Энергия** (электроэнергия, топливо)
8. **Финансовые продукты** (кредиты, страховки, акции — особые правила)

Каждый товар имеет атрибуты:

```yaml
good:
  id: coffee_beans_green
  name: "Кофейное зерно (зелёное)"
  category: raw
  unit: kg
  base_world_price: 3.20      # $/кг на старте 2000 года
  perishability: 0.002        # доля порчи в день при обычном хранении
  storage: dry                # dry | cold | frozen | liquid | gas | hazardous | none
  weight_per_unit: 1.0        # кг, для логистики
  volume_per_unit: 0.0015     # м³
  quality_range: [1, 5]       # класс качества
  price_elasticity: -0.3      # для B2B — низкая
  substitutes: [coffee_beans_robusta]
  tags: [food, agricultural, tradable]
```

### Качество
Каждая партия товара имеет **качество Q ∈ [1..5]** (в UI — звёзды). Качество выхода = f(качество входов, оборудование, квалификация персонала, технологии). Высокое качество → выше цена и лояльность, но дороже производство.

```
Q_out = clamp( w_in·avg(Q_inputs) + w_eq·Q_equipment + w_staff·Q_staff + w_tech·TechBonus , 1, 5 )
```
Веса задаются для каждого рецепта (например, у кофейни w_staff высокий — бариста важен; у НПЗ w_eq высокий).

## 3.3 Спрос домохозяйств

Для каждого города, квинтиля дохода и потребительского товара/услуги:

```
D_base = Население_квинтиля × Потребление_на_душу(товар, доход, культура, сезон, время суток)
```

Затем спрос распределяется между продавцами в «зоне охвата» через **логит-модель выбора** (как в реальных моделях потребительского выбора):

```
U_ij = β_price·ln(P_j) + β_qual·Q_j + β_brand·Brand_j + β_dist·Distance_ij
       + β_wait·Queue_j + β_loyal·Loyalty_ij + ε

Share_j = exp(U_ij) / ( Σ_k exp(U_ik) + exp(U_outside) )
```

- `U_outside` — «не покупать / купить у фоновых мелких продавцов / приготовить дома». Высокие цены повышают долю «не покупать».
- Коэффициенты β зависят от **квинтиля** (бедные чувствительнее к цене, богатые — к качеству и бренду) и **категории** (бензин — цена/расстояние; одежда — бренд; медицина — качество).
- **Зона охвата** зависит от типа бизнеса: кофейня ~500 м, супермаркет ~2 км, автосалон — весь город, онлайн-магазин — вся страна (с учётом доставки).

### Эластичность
Совокупная ценовая эластичность получается из модели, но калибруется по таблице:

| Категория | Эластичность (ориентир) |
|---|---|
| Хлеб, базовые продукты | -0,2 … -0,4 |
| Бензин | -0,3 (краткоср.) / -0,7 (долгоср.) |
| Кофе на вынос | -0,8 |
| Рестораны | -1,2 |
| Электроника | -1,5 |
| Авиаперелёты (туризм) | -1,8 |
| Люкс | -0,5 (эффект Веблена у верхнего квинтиля, может быть > 0) |

### Суточная/сезонная кривая
Каждая B2C-категория имеет профиль:
- Кофейня: пик 7–10, малый пик 14–16, ноль после 21.
- Бар: 18–02, пятница/суббота ×2.
- Мороженое: лето ×3, зима ×0,3 (зависит от климата).
- Отели: туристический сезон, выходные.
- Отопление/газ: зима.

## 3.4 B2B-рынки

Для промежуточных товаров существуют **два канала**:

1. **Спотовый рынок (биржа товаров)** — региональный (макрорегион) + мировой. Ордербук упрощённый: каждый день игроки и ИИ выставляют предложения (объём, мин. цена) и заявки (объём, макс. цена); клиринг по **единой цене равновесия** (call auction). Транспорт до покупателя оплачивается отдельно.
2. **Контракты** — двусторонние договоры (объём/период, цена фиксированная или индексированная, качество, штрафы). Основной канал для стабильности. См. главу 08.

### Формирование спотовой цены

```
P_t+1 = P_t × (1 + k × (D_t − S_t) / max(S_t, ε))   — если книга заявок тонкая (мало участников)
P_t+1 = clearing_price(bids, asks)                   — если ликвидность достаточна
```
+ ограничение дневного изменения (лимит ±10%, кроме кризисов) + запаздывание ожиданий (ИИ-трейдеры используют скользящие средние).

**Мировая цена** (внешний мир) задаёт «пол» и «потолок»: если внутри региона цена выше мировой + транспорт + пошлина → импорт; если ниже мировой − транспорт − пошлина → экспорт. Это не даёт ценам улетать в бесконечность и делает пошлины значимыми.

## 3.5 Себестоимость и ценообразование

Каждый бизнес считает себестоимость единицы продукции:

```
Unit_Cost = Σ(input_qty × input_price) / batch
          + Labor_cost / output
          + Energy_cost / output
          + Rent_or_Depreciation / output
          + Logistics / output
          + Overhead_allocation / output
```

Игрок задаёт цену одним из способов:
- **Ручная цена.**
- **Наценка** (cost-plus, % к себестоимости).
- **Относительно рынка** (−5% от средней конкурентов).
- **Динамическая** (требует ПО «Pricing AI» — продукт IT-отрасли!): максимизация прибыли по оценённой кривой спроса.

## 3.6 Рынок труда

- Пулы работников в каждом городе по **специальностям** (≈25): неквалифицированный, продавец, повар, бариста, водитель, механик, медсестра, врач, инженер-механик, инженер-химик, программист, data scientist, дизайнер, маркетолог, бухгалтер, юрист, менеджер, топ-менеджер, геолог, пилот, моряк, строитель, электрик, учёный, трейдер.
- Зарплата = f(спрос/предложение специалистов в городе, ВВП, мин. зарплата, квалификация).
- **Конкуренция за кадры:** если IT-гиганты игроков переманивают программистов, зарплаты растут для всех; можно открыть **частный университет/курсы** (бизнес тира II–III), чтобы растить пул.
- Миграция: высокие зарплаты медленно привлекают работников из других городов.

## 3.7 Макроэкономика

### Экономический цикл
Каждая страна имеет фазу цикла: **рост → пик → рецессия → дно**. Параметры: рост ВВП, безработица, инфляция, ставка ЦБ. Связь между странами через торговлю (рецессия в США → спад экспорта Китая → спад сырья в Австралии).

```
ВВП_t+1 = ВВП_t × (1 + g_trend + g_cycle + Σ шоки + вклад_игроков)
```
**Вклад игроков** реален: если игроки строят много фабрик в стране, растёт занятость → доход → спрос. Крупный игрок, закрыв заводы, может спровоцировать локальную рецессию.

### Инфляция и ЦБ
- Инфляция = f(рост денежной массы, разрыв выпуска, цены на энергию, курс).
- ЦБ следует упрощённому правилу Тейлора: `ставка = r* + π + 0.5(π − π*) + 0.5·output_gap`.
- Ставка ЦБ → ставки по кредитам (ставка + спред по рейтингу компании) → инвестиции.

### Валюты
- Каждая страна (или валютный союз, напр. Еврозона) имеет курс к игровому доллару.
- Курс плавает от торгового баланса, разницы ставок, событий.
- **Валютный риск:** прибыль бразильской «дочки» в реалах при девальвации теряет в долларах.
- Банки/трейдеры игроков могут хеджировать (форварды) — продукт финансового сектора.

### Энергия как «кровь» экономики
Цена нефти/газа/электроэнергии входит в себестоимость почти всего (транспорт, производство, отопление). Это **главная ось взаимосвязи**:
- Нефтяной магнат, сокративший добычу → дорожает логистика → дорожает кофе в кофейне соседа.
- Энергетическая компания с ВИЭ → дешёвое электричество для датацентров IT-игрока.

## 3.8 Каскадные взаимосвязи (примеры)

| Событие | Цепочка влияния |
|---|---|
| Засуха в Бразилии | ↓ урожай кофе → ↑ цена зерна → ↑ себестоимость кофеен → кофейни повышают цены → часть клиентов уходит к чаю → ↑ спрос на чай (Индия) |
| Игрок строит 5 НПЗ в Европе | ↑ предложение бензина → ↓ цена топлива → ↓ стоимость логистики → ↓ цены в ритейле → ↑ маржа у ритейлеров |
| Игрок-IT выпускает «Logistics OS» | Логистические компании покупают → ↑ эффективность −10% затрат → игрок-IT получает подписку + данные о рынке |
| Дефицит чипов | ↑ цена чипов → автопром снижает выпуск → ↑ цена б/у авто → автосервисы ↑ спрос |
| Банк игрока поднял ставки | ↓ кредитование малого бизнеса в городе → меньше новых ИИ-конкурентов → ↑ доля существующих |
| Рост туризма в городе | ↑ отели/рестораны/такси → ↑ аренда в центре → кофейни вытесняются в спальные районы |
| Повышение мин. зарплаты | ↑ ФОТ ритейла → ↑ спрос на автоматизацию (кассы самообслуживания — продукт электроники + ПО) |
| Карбоновый налог | ↓ маржа угля/нефти → ↑ инвестиции в ВИЭ → ↑ спрос на литий/медь → рудники дорожают |

## 3.9 Бухгалтерия фирмы (на уровне симуляции)

Каждый бизнес-юнит ведёт:
- **Запасы** (по товарам, партиям, качеству, сроку годности).
- **Мощности** (рецепты, производительность, загрузка, износ).
- **Персонал** (количество по специальностям, навык, мораль).
- **Денежные потоки** (ежедневно), **P&L** (месяц/квартал/год), **баланс** компании.

Деньги не создаются из воздуха: все платежи — переводы между агентами (кроме «внешнего мира» и эмиссии ЦБ). Это гарантирует замкнутость и позволяет PvP-игрокам реально «высасывать» деньги друг у друга.

## 3.10 Упрощение для производительности

| Элемент | Частота расчёта | Метод |
|---|---|---|
| Поток клиентов в B2C | Каждый тик (час) | Логит по предрасчитанным полезностям, обновляемым раз в день |
| Производство | Каждый тик | Простая скорость по рецептам |
| Спотовые рынки | Раз в игровой день | Аукционный клиринг |
| Цены труда | Раз в неделю | Равновесие спрос/предложение |
| Макро (ВВП, инфляция, курсы) | Раз в месяц | Формулы с шоками |
| Фоновые ИИ-бизнесы | Раз в день, агрегировано | «Рыночная плотность» без индивидуальной симуляции |
| Демография городов | Раз в квартал | |

Целевой бюджет: **< 30 мс** на дневной шаг симуляции на сервере для сессии из 8 игроков и 200 ИИ-корпораций (≈20–50 тыс. бизнес-юнитов).
