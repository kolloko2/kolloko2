# 06. Операционное управление: персонал, маркетинг, качество, R&D

## 6.1 Персонал

### 6.1.1 Модель работника
Рядовой персонал моделируется **группами** (не поштучно), топ-менеджеры и ключевые специалисты — **поимённо**.

| Атрибут | Группа (рядовые) | Именной (ключевые) |
|---|---|---|
| Специальность | ✓ | ✓ |
| Навык (1–100) | Среднее по группе | Индивидуальный |
| Зарплата | Средняя | Индивидуальная, переговоры |
| Мораль (0–100) | ✓ | ✓ |
| Лояльность | — | ✓ (риск ухода к конкуренту) |
| Черты | — | 2–3 черты (см. ниже) |
| Опыт | Растёт со временем | Растёт + уровни |

### 6.1.2 Мораль
```
Мораль = база
       + f(зарплата / рыночная_зарплата)        # ±30
       + соцпакет (ДМС, питание, обучение)      # до +15
       + условия (оборудование, офис)           # ±10
       + перегрузка (загрузка > 100%)           # до −25
       + бренд работодателя                      # ±10
       + события (бонусы, увольнения, забастовки)
```
- Мораль < 40 → производительность −20%, текучесть ↑, риск забастовки (если сильны профсоюзы).
- Мораль > 80 → производительность +10%, качество обслуживания +0,3★.

### 6.1.3 Найм
- Рынок труда города: пул доступных по специальности, распределение навыков, ожидаемая зарплата.
- Способы: объявление (дёшево, медленно), кадровое агентство (бизнес тира II — может быть чужой!), **хедхантинг** у конкурента (дорого, переманивает конкретного именного специалиста).
- Обучение: курсы повышают навык группы; собственная корпоративная академия (тир III).

### 6.1.4 Ключевые персонажи (именные)
Роли: **управляющий точкой, региональный директор, директор подразделения (COO/CFO/CMO/CTO), шеф-повар, ведущий инженер, главный геолог, ведущий учёный, звёздный трейдер, звезда кино/ТВ**.

**Черты (примеры):**
| Черта | Эффект |
|---|---|
| Экономный | −5% OPEX подразделения |
| Харизматичный | +мораль команды, +бренд |
| Новатор | +15% R&D |
| Перфекционист | +0,3★ качества, −5% скорость |
| Жадный | Требует +20% к зарплате, риск ухода к конкуренту за деньги |
| Лоялист | Почти не уходит |
| Коррумпированный | +скорость лицензий, риск скандала |
| Агрессивный переговорщик | Лучшие условия контрактов (+3–7%) |
| Аналитик | Точнее прогнозы рынка в отчётах |
| Выгоревший | Временный −20%, нужен отпуск |

### 6.1.5 Очки внимания и делегирование
Игрок как владелец имеет **Очки Внимания (ОВ)** — лимит количества бизнес-юнитов, которыми можно управлять в ручном режиме без штрафов.
- Базово: 5 ОВ. Каждый бизнес без управляющего потребляет 1 ОВ.
- Превышение → «хаос»: −эффективность всех неуправляемых юнитов.
- **Управляющий** снимает нагрузку с 1 точки; **региональный директор** — до 20 точек; **директор подразделения** — целая отрасль.
- Менеджеры работают по **политикам**, заданным игроком (ценовая стратегия, запасы, найм, бюджет маркетинга), и принимают решения в рамках своего навыка.
- Это ключ к масштабированию: на тире IV игрок не трогает отдельные кофейни, а меняет политики подразделения «Ритейл-Еда».

### 6.1.6 Профсоюзы и трудовые отношения
- В странах с сильными профсоюзами: коллективные договоры, требования индексации, забастовки (остановка юнита на N дней).
- Решения: уступить, переговоры, автоматизация (долгосрочно), закрытие (риск репутации).

## 6.2 Маркетинг и бренд

### 6.2.1 Бренд
Каждый бренд (у игрока их может быть несколько: «КофеЛав» — масс-маркет, «Black Bean» — премиум) имеет параметры:

| Параметр | Описание |
|---|---|
| **Узнаваемость (Awareness)** | % целевой аудитории региона, знающей бренд. Растёт от рекламы и присутствия точек, затухает без поддержки (−2–5%/мес) |
| **Восприятие качества** | Средний опыт клиентов (лаг относительно реального качества) |
| **Ценовое позиционирование** | Эконом / средний / премиум / люкс |
| **Лояльность** | Доля повторных покупателей |
| **Репутация (этика)** | Скандалы, экология, отношение к персоналу; влияет на определённые сегменты и на отношения с государством |
| **Ассоциации** | Теги: «быстро», «уютно», «экологично», «технологично» — от действий игрока |

Бренд — **переносимый актив**: известный бренд кофеен облегчает запуск бренда кофе в пачках (brand extension), но провал расширения бьёт по материнскому бренду.

### 6.2.2 Рекламные каналы

| Канал | Охват | Таргетинг | Стоимость | Поставщик |
|---|---|---|---|---|
| Листовки/промоутеры | Район | Низкий | $ | Копицентр/типография |
| Наружная реклама (билборды) | Город | Гео | $$ | Медиа-оператор наружки |
| Радио | Город/регион | Средний (по станции) | $$ | Радио (игрок/ИИ) |
| Печатные СМИ | Регион | Средний | $$ | Издательство |
| ТВ | Страна | Низкий, огромный охват | $$$$ | ТВ-канал |
| Поисковая реклама | Страна/мир | Высокий (намерение покупки) | $$–$$$ | Поисковик (игрок/ИИ) |
| Соцсети | Страна/мир | Очень высокий | $$–$$$ | Соцсеть (игрок/ИИ) |
| Инфлюенсеры | Нишевой | Высокий | $$ | Медиа |
| Спонсорство (спорт, события) | Страна | Низкий, сильный бренд-эффект | $$$$ | События |
| Программы лояльности | Существующие клиенты | Максимальный | $ + ПО | IT |
| Промо-акции/скидки | Точка | — | Потеря маржи | — |

**Модель эффекта рекламы:**
```
ΔAwareness = (1 − Awareness) × ( 1 − exp(−k_канала × GRP × креатив_качество) )
```
Убывающая отдача; частота важнее разового залпа; креатив зависит от рекламного агентства.

### 6.2.3 PvP-маркетинг
- **Сравнительная реклама** — снижает восприятие качества конкурента (риск суда, если ложь).
- **Медиакампания против конкурента** (через медиахолдинг) — расследования, скандалы; требует «компромата» (из промышленного шпионажа или реальных провалов соперника).
- **Захват рекламного инвентаря** — выкупить все билборды в городе на квартал до открытия конкурента.

## 6.3 Качество и операционная эффективность

### 6.3.1 Качество
Итоговое качество продукта/услуги (★1–5) = входы + оборудование + персонал + технологии (см. 03-economy). Для услуг добавляется:
- **Время ожидания** (очередь) — при загрузке > 85% качество падает экспоненциально.
- **Атмосфера** (дизайн, чистота — клининг!).
- **Стабильность** — дисперсия качества (сети ценят предсказуемость).

### 6.3.2 Оборудование
- Каждое оборудование имеет **износ** (0–100%). Обслуживание — ежемесячно; без него — поломки (простой) и падение качества.
- Поколения оборудования (через R&D/рынок): новое = эффективнее/качественнее.
- Можно покупать б/у (на вторичном рынке — в т.ч. у обанкротившихся игроков!).

### 6.3.3 Отчёты и аналитика
- По каждому юниту: P&L, KPI, тренды, сравнение с бенчмарком отрасли.
- **Аналитика конкурентов** — видимость зависит от «разведки рынка»: базово видны цены и рейтинг; маркетинговые исследования (услуга) раскрывают долю рынка и объёмы; промышленный шпионаж — себестоимость и контракты.

## 6.4 R&D и дерево технологий

### 6.4.1 Механика
- R&D-очки производятся **R&D-центрами** (здания с учёными/инженерами) и отделами внутри компаний.
- Технологии принадлежат **компании игрока** (не глобальны). Однако:
  - Мировой уровень технологий растёт со временем (ИИ тоже исследуют) — отставание = неконкурентность.
  - Технологии можно **лицензировать** другим игрокам (роялти) или **купить** лицензию.
  - **Патенты** защищают на 20 игровых лет; нарушение → суд.
  - **Утечка технологий** — через переманивание инженеров и шпионаж.

### 6.4.3 Эпохи
При старте в 2000 году часть технологий заблокирована **мировым уровнем** до определённого года (нельзя изобрести смартфон в 2001), но игрок с огромными инвестициями может опередить мир на 2–4 года — и получить монопольную ренту первопроходца.

### 6.4.4 Каталог программных продуктов (для IT-игроков)
Продукты ПО, которые IT-компания игрока может разработать и продавать — и которые дают **бонусы покупателям**:

| Продукт | Покупатели | Бонус покупателю | Требуемая технология |
|---|---|---|---|
| POS-система | Кофейни, рестораны, ритейл | +5% пропускная способность касс, данные продаж | ПО ур.1 |
| Бухгалтерия/ERP | Все | −5% накладных, точные отчёты | ПО ур.1–2 |
| CRM / лояльность | B2C | +8% удержание | Ритейл ур.2 |
| Логистика (Fleet/WMS) | Логистика, склады, производители | −10–20% логистических затрат | Логистика ур.1–3 |
| Динамическое ценообразование | Ритейл, отели, авиалинии | +3–8% маржи | ПО ур.3 |
| Бронирование | Отели, рестораны, клиники | +загрузка | ПО ур.2 |
| Агро-аналитика | Фермы | +10% урожайность | Агро ур.3 |
| Банковский core | Банки | −операционные затраты, новые продукты | Финансы ур.1 |
| Торговый терминал | Трейдеры, фонды | Доступ к алготрейдингу | Финансы ур.3 |
| Антивирус/кибербезопасность | Все | Защита от кибератак (событие) | ПО ур.2 |
| Офисный пакет / ОС | Все B2B + B2C | Массовый рынок | ПО ур.1–2 |
| Мобильные игры | B2C | — (прямой B2C-доход) | ПО ур.3 |
| Платформа такси/доставки | Таксопарки, рестораны | Агрегатор: комиссия с каждого заказа | ПО ур.3 |
| ИИ-ассистент | Все | +ОВ, автоматизация | ПО ур.5 |

**PvP-нюанс:** IT-игрок, продающий ERP соперникам, получает **агрегированные данные** об их операциях (если это прописано в EULA — репутационный риск при раскрытии).
