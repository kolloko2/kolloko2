# 05. Производственные цепочки и логистика

## 5.1 Принцип

Каждый производственный бизнес работает по **рецептам**:

```yaml
recipe:
  id: roast_coffee
  building: coffee_roastery
  inputs:
    - { good: coffee_beans_green, qty: 1.20 }   # кг (потеря веса 16–20% при обжарке)
    - { good: natural_gas, qty: 0.15 }          # м³
    - { good: packaging_bag, qty: 4 }           # пакеты по 250 г
  outputs:
    - { good: coffee_roasted, qty: 1.0 }        # кг
  time_hours: 0.05                              # на единицу при 1 ростере
  labor: { roaster_operator: 1 }
  quality_weights: { inputs: 0.5, equipment: 0.2, staff: 0.25, tech: 0.05 }
```

Бизнес может иметь несколько рецептов; игрок выбирает, какие запускать и в какой пропорции (например, НПЗ — бензиновый или дизельный режим).

## 5.2 Полное дерево товаров

Условные обозначения: **[С]** сырьё, **[П]** полуфабрикат, **[К]** компонент, **[Т]** потребительский товар, **[У]** услуга, **[Э]** энергия.

## 5.3 Закупки: источники входов

Для каждого входа бизнеса игрок выбирает **источник(и)** с приоритетом:

1. **Свой бизнес (внутригрупповой)** — по трансфертной цене (себестоимость, рыночная или ручная). Трансфертное ценообразование влияет на налоги в разных странах (легальная оптимизация vs. риск налоговой проверки).
2. **Контракт с другим игроком/ИИ** — фиксированные условия (глава 08).
3. **Спотовый рынок** — по текущей цене, без гарантий наличия.
4. **Импорт («внешний мир»)** — всегда есть, но дорого (мировая цена + наценка 10–30% + пошлины + долгая доставка).

### Политики закупок
- **Минимальный запас (safety stock)** — дни покрытия.
- **Точка заказа / объём заказа** (EOQ можно рассчитать автоматически при наличии ПО).
- **Предпочтение по качеству** (мин. звёзды).
- **Лимит цены** («не покупать дороже $X»).
- **Резервный источник**, если основной не поставил.

## 5.4 Логистика

### 5.4.1 Модель доставки
Каждая поставка = **груз** (товар, количество, вес, объём, требование к хранению) + **маршрут** (сегменты) + **перевозчик** (свой/чужой/ИИ).

```
Стоимость = Σ_по_сегментам ( тариф_вида_транспорта × т·км × коэф_топлива ) + погрузка/разгрузка + таможня + страховка
Время     = Σ ( расстояние / скорость ) + время_терминалов + таможня
Порча     = perishability × время × (1 − защита_вида_транспорта)
```

### 5.4.2 Виды транспорта

| Вид | Скорость | Тариф ($/т·км, база) | Чувствительность к цене топлива | Когда использовать |
|---|---|---|---|---|
| Фургон | 50 км/ч (город) | 0,40 | Высокая | Последняя миля, кофейни, рестораны |
| Грузовик | 70 км/ч | 0,08 | Высокая | До 1 500 км |
| Рефрижератор | 70 км/ч | 0,12 | Высокая | Скоропорт |
| Цистерна | 65 км/ч | 0,10 | Высокая | Топливо, молоко, химия |
| Ж/д | 40 км/ч (с остановками) | 0,03 | Средняя (электрификация снижает) | Сыпучие, контейнеры, 500–5 000 км |
| Морской балкер/танкер | 25 км/ч | 0,005 | Средняя | Сырьё межконтинентально |
| Контейнеровоз | 35 км/ч | 0,008 | Средняя | Готовые товары межконтинентально |
| Авиагруз | 800 км/ч | 1,50 | Очень высокая | Электроника, цветы, фарма, срочное |
| Трубопровод | — (поток) | 0,01 | Низкая (насосы) | Нефть, газ |
| ЛЭП | мгновенно | потери 2–8% на 1 000 км | — | Электроэнергия |

### 5.4.3 Собственный vs. сторонний транспорт
- **Сторонний** (логистические компании игроков/ИИ): платите тариф, нет CAPEX, зависимость от перевозчика.
- **Собственный автопарк**: CAPEX + водители + ТО + топливо; выгоден при стабильных объёмах; «пустой обратный рейс» можно продавать как услугу.
- **Маршрутизация:** при наличии ПО «Fleet Manager» — автоматическая оптимизация (−10–20% затрат).

### 5.4.4 Склады и узлы
- Склады — буферы в цепочке; распределительные центры позволяют снабжать много точек одним крупным заказом (экономия на масштабе).
- Холодная цепь: скоропорт требует холодильных складов/рефрижераторов на всём пути, иначе — порча и падение качества.
- **Кросс-докинг** — перегрузка без хранения (быстрее, дешевле, нужен хороший склад + ПО).

### 5.4.5 Узкие места и события
- Каналы (Суэцкий, Панамский), проливы (Малаккский, Ормузский, Босфор) — могут быть заблокированы (событие) → удлинение маршрутов, рост фрахта.
- Забастовки докеров, закрытие границ, санкции, пробки, снегопады.
- Порт с низкой пропускной способностью → очереди судов. Игрок может **инвестировать в порт** (концессия).

## 5.5 Вертикальная и горизонтальная интеграция

### Вертикальная интеграция (пример «Кофейная империя»)
```
Плантация (Колумбия) ─▶ Экспортный терминал ─▶ Контейнеровоз ─▶ Порт (Роттердам)
  ─▶ Склад ─▶ Обжарка (Германия) ─▶ Распределительный центр ─▶ Сеть кофеен (Европа, 200 точек)
                                                              ─▶ Супермаркеты (продажа пачек)
                                                              ─▶ Франчайзи
```
**Плюсы:** маржа на каждом звене, контроль качества (+бренд), защита от дефицита, информация о рынке.
**Минусы:** огромный капитал, сложность, риск концентрации (засуха бьёт по всей цепочке), мощности простаивают при спаде.

**Бонус синергии:** каждый внутренний переход в цепочке даёт −3% транзакционных издержек и +0,1 качества (меньше перегрузок, стандарты). Механика поощряет интеграцию, но не делает её обязательной.

### Горизонтальная интеграция
- Покупка конкурентов того же уровня → доля рынка, ценовая власть, экономия на масштабе.
- Ограничена антимонопольным регулятором (глава 09).

### Конгломерат (диверсификация)
- Владение несвязанными отраслями снижает риск (контрциклические отрасли: в рецессию ломбарды и дискаунтеры растут, рестораны падают).

## 5.6 Пример «всё связано» — путь смартфона

```
Чили: литий (рудник игрока A) ──────────────────────┐
Конго: кобальт (ИИ) ────────────────────────────────┤
Китай: редкоземельные (ИИ) ──▶ магниты ──────────────┤
Тайвань: чипы (фабрика игрока B, 7нм) ───────────────┤
Корея: OLED-экраны (ИИ) ─────────────────────────────┤
Саудовская Аравия: нефть (игрок C) ─▶ пластик ───────┤
                                                      ▼
                    Вьетнам: сборка смартфонов (игрок B)
                                                      │ контейнеровоз (судоходство игрока D)
                                                      ▼
            США: склад ─▶ магазины электроники (игрок A) + e-com (игрок D)
                                                      │
                                                      ▼
            Потребитель покупает смартфон + подписку (телеком игрока C) + приложения (SaaS игрока B)
```
Каждый из 4 игроков зависит от остальных → естественные поводы для **контрактов, союзов, шантажа и ценовых войн**.
