# 04. Каталог бизнесов

Всего **64 типа бизнеса** в 5 тирах и 12 отраслях. Каждый бизнес — это набор **модулей** (помещение, оборудование, персонал, рецепты, склад) и **политик** (цены, закупки, маркетинг).

## 4.0 Общая схема карточки бизнеса

| Поле | Описание |
|---|---|
| **Тир / отрасль** | Определяет порог входа и связи |
| **Размещение** | Где можно открыть (тип участка, зонирование, район) |
| **CAPEX** | Стартовые вложения (ремонт, оборудование, лицензии) — диапазон зависит от страны/района |
| **OPEX** | Ежемесячные расходы помимо закупок: аренда, ФОТ, коммуналка, обслуживание |
| **Входы** | Что потребляет (товары, энергия, услуги) — покупается на рынке, по контракту или у своих же бизнесов |
| **Выходы** | Что продаёт и кому (B2C / B2B / госзаказ) |
| **Персонал** | Роли и количество для базового уровня |
| **KPI** | Главные метрики эффективности |
| **Апгрейды** | Модули, повышающие мощность/качество/эффективность |
| **Риски** | Специфические угрозы |
| **Связи** | С какими отраслями игрок интегрируется |
| **Разблокировка** | Условия доступа |

Цены указаны **для базовой страны (США, 2000 г.)**, в других странах умножаются на региональные коэффициенты (аренда, зарплата, налоги).

## 4.2 Тир I — Малый бизнес (стартовый)

### ☕ Кофейня *(эталонная карточка — максимально подробно)*

| Поле | Значение |
|---|---|
| **Отрасль** | Еда и напитки |
| **Размещение** | Помещение 30–150 м², зонирование «Коммерция»/«Смешанное», первый этаж. Лучшие районы: CBD, студенческий, исторический центр |
| **CAPEX** | $25 000 – $80 000: ремонт ($8–30K), кофемашина ($5–25K), кофемолка ($1–3K), мебель ($3–15K), холодильник, касса/POS ($1K), вывеска ($1–5K), разрешения ($0,5–3K) |
| **OPEX/мес** | Аренда $1,5–12K, ФОТ $6–20K, коммунальные $0,5–1,5K, обслуживание оборудования $200, ПО кассы $50 |
| **Входы** | Обжаренный кофе (≈18 г/чашку), молоко (≈150 мл на молочный напиток), сахар, сиропы, стаканы+крышки (на вынос), выпечка (опционально — с пекарни), чай, вода, электроэнергия |
| **Выходы (B2C)** | Эспрессо, американо, капучино, латте, раф, чай, выпечка, сэндвичи (при наличии кухни). Средний чек $3,5–6 |
| **Мощность** | 1 бариста ≈ 40–60 напитков/час; 1 кофемашина (2 группы) ≈ 120 напитков/час |
| **Персонал** | 2–6 бариста (посменно), 1 управляющий (опц.), 1 кассир (опц. при потоке > 80/час) |
| **KPI** | Чашек/день, средний чек, время ожидания, рейтинг (1–5), себестоимость чашки, загрузка мест, % на вынос |
| **Апгрейды** | Вторая кофемашина (+мощность), премиум-машина (+0,5 качества), зал/терраса (+места, +время пребывания, +ланч), мини-кухня (сэндвичи, завтраки), окно «на вынос», мобильный заказ (требует ПО — продукт IT), программа лояльности (+удержание), авторская обжарка (+бренд), вечернее меню/алкоголь (лицензия) |
| **Риски** | Конкурент открывается напротив; рост цены зерна; поломка кофемашины (простой 1–3 дня); санинспекция; уход лучшего бариста; повышение аренды при продлении |
| **Связи** | ← Обжарка кофе ← Плантация; ← Молочная ферма; ← Пекарня; ← Производство упаковки (← пластик/бумага ← НПЗ/лесопилка); → Сеть кофеен (франшиза); ↔ Рекламное агентство; ↔ IT (приложение) |
| **Разблокировка** | Доступна с начала |

**Пример экономики одной кофейни (CBD, США, 2000):**

| Статья | В месяц |
|---|---|
| Продажи: 350 чашек/день × 30 × $3,8 | $39 900 |
| Выпечка: 80 шт/день × 30 × $2,5 | $6 000 |
| **Выручка** | **$45 900** |
| Себестоимость кофе/молока/стаканов (≈$0,85/чашка) | −$8 925 |
| Себестоимость выпечки (закупка с пекарни $1,2) | −$2 880 |
| Аренда (80 м² × $90) | −$7 200 |
| ФОТ (5 бариста × $2 000 + управляющий $3 500) | −$13 500 |
| Коммунальные, обслуживание, ПО | −$1 600 |
| Реклама | −$1 000 |
| Налог с продаж (вкл. в цену; учтён) | — |
| **EBITDA** | **$10 795** |
| Амортизация (CAPEX $55K / 60 мес) | −$917 |
| Налог на прибыль 25% | −$2 470 |
| **Чистая прибыль** | **≈$7 400** (окупаемость ≈ 7–8 мес. при хорошей локации; 18+ мес. при средней) |

**Микрорешения игрока в кофейне:**
- Цена каждой позиции; ассортимент (больше позиций — шире аудитория, но сложнее закупки).
- Сорт/поставщик зерна (арабика/робуста, качество, своя обжарка).
- Часы работы и смены.
- Количество мест vs. на вынос.
- Дизайн (уютный/минимализм/премиум) → влияет на сегмент клиентов.

### 🥐 Пекарня
| Поле | Значение |
|---|---|
| Размещение | 50–300 м², спальный район, центр |
| CAPEX | $40–120K (печи, тестомесы, витрины) |
| Входы | Мука, сахар, масло, яйца, дрожжи, начинки, газ/электричество, упаковка |
| Выходы | B2C: хлеб, выпечка, торты; **B2B: поставки в кофейни, рестораны, мини-маркеты** |
| Персонал | 2–4 пекаря (ночные смены), 1–2 продавца |
| KPI | Списания (скоропорт 1–2 дня!), доля B2B, загрузка печей |
| Апгрейды | Конвекционные печи, кондитерский цех, линия заморозки (позволяет хранить), фургон доставки |
| Риски | Списания нераспроданного, рост цен на муку |
| Связи | ← Мельница ← Ферма зерна; → Кофейни, рестораны, супермаркеты |

### 🌭 Фастфуд-киоск / фудтрак
| Поле | Значение |
|---|---|
| Размещение | 6–20 м² или мобильный (фудтрак можно перемещать между точками раз в день!) |
| CAPEX | $10–45K |
| Входы | Булки, сосиски/мясо, овощи, соусы, напитки, упаковка, газ/топливо |
| Выходы | B2C: хот-доги, шаурма, бургеры. Чек $3–7 |
| Персонал | 1–3 |
| Особенность | **Мобильность:** фудтрак ставится у стадиона в день матча, у офисов в обед |
| Связи | ← Мясокомбинат, пекарня; → эволюционирует в сеть фастфуда |

### 🏪 Мини-маркет («у дома»)
| Поле | Значение |
|---|---|
| Размещение | 50–200 м², жилые районы |
| CAPEX | $30–90K (стеллажи, холодильники, касса, начальный товар) |
| Входы | 100–400 SKU: продукты, напитки, бытовая химия, табак/алкоголь (лицензия) |
| Выходы | B2C, маржа 15–30% |
| Персонал | 2–5 продавцов-кассиров |
| KPI | Оборачиваемость запаса, out-of-stock %, порча, средний чек |
| Механика | **Ассортиментная матрица** — выбор категорий; автозаказ при пороге запаса |
| Связи | ← Оптовые дистрибьюторы, пищевые фабрики; → сеть супермаркетов |

### 💐 Цветочный магазин
- CAPEX $15–40K; входы: срезанные цветы (скоропорт 5–7 дней, поставки самолётом из Нидерландов/Эквадора/Кении!), упаковка, холодильная витрина.
- Спрос — пики: 14 февраля, 8 марта, 1 сентября, свадьбы (сезон).
- Связи: ← Теплицы/плантации, ← авиалиния (логистика); → свадебный бизнес, корпоративные клиенты.

### 👕 Прачечная / химчистка
- CAPEX $40–100K (машины), входы: вода, электричество, химия.
- Выходы: B2C + **B2B (отели, рестораны, клиники)** — контракты.
- Персонал: 2–4. Связь: ← Химзавод; → Отели, клиники.

### 💈 Барбершоп / салон красоты
- CAPEX $20–60K; входы: косметика, инструменты, ПО записи.
- Ключевой ресурс — **мастера** (навык = рейтинг = цена). Мастер может уйти к конкуренту с частью клиентов.
- Апгрейды: маникюр, косметология (лицензия), собственная линия косметики (→ химзавод).

### 🚗 Автомойка
- Размещение: участок у дороги 150–600 м²; CAPEX $50–250K (ручная → портальная → туннельная).
- Входы: вода, химия, электричество. Выходы: B2C + B2B (таксопарки, автодилеры).
- Спрос: погода (после дождя/снега ×2, во время дождя ×0,2).

### 🖨 Копицентр / типография
- CAPEX $20–80K; входы: бумага, тонер, электричество.
- Выходы: B2C (студенты), **B2B — печать рекламы для других бизнесов** (листовки, вывески).
- Эволюция → Типография → Рекламное агентство / полиграфический комбинат.

### 🚕 Такси (1–3 машины)
- CAPEX: $15–30K за авто (или лизинг). Входы: топливо, ТО, страховка, водители.
- Выходы: поездки B2C; B2B — корпоративные контракты, доставка.
- Эволюция → таксопарк → курьерская служба → логистика. Позже — **платформа такси** (IT) или **беспилотники** (технология).

### 🔧 Ремонт телефонов/техники
- CAPEX $5–20K; входы: запчасти (← производство электроники), инструменты.
- Выход: услуги ремонта, продажа б/у. Эволюция → магазин электроники / сервисный центр бренда.

### 💊 Аптека
- Требует **лицензии** (фармацевт в штате). CAPEX $50–150K.
- Входы: лекарства (← дистрибьютор ← фармзавод), косметика.
- Высокая стабильность спроса, низкая эластичность, госрегулирование цен на «жизненно важные».

### 🏦 Ломбард / обменный пункт
- CAPEX $20–50K + оборотный капитал (кэш!).
- Ломбард: выдаёт займы под залог (золото, техника), продаёт невыкупленное. Обменник: зарабатывает на спреде курсов.
- Первый шаг в финансы. Риски: ограбление (охрана — услуга B2B), регулятор.

### 🌱 Огород/теплица (мини-ферма)
- Участок в пригороде; CAPEX $10–60K. Выход: овощи, зелень, цветы (B2B рестораны «фермерские продукты» с премией качества).

## 4.3 Тир II — Средний бизнес

### 🍽 Ресторан
| Поле | Значение |
|---|---|
| CAPEX | $150K – $1,5M (зависит от концепции) |
| Концепции | Фастфуд, casual dining, этнический (итальянский, японский, грузинский…), fine dining (требует шеф-повара ★★★★+) |
| Входы | Мясо, рыба, овощи, молочка, мука, специи, алкоголь (лицензия), напитки, газ, электричество, клининг, прачечная |
| Персонал | Шеф, повара (3–15), официанты (4–20), бармен, хостес, посудомойщики, менеджер |
| KPI | Food cost % (цель 28–35%), заполняемость, оборачиваемость столов, рейтинг, средний чек |
| Механика | **Меню-конструктор**: блюдо = рецепт из ингредиентов → себестоимость → цена. **Рейтинг критиков** (событие: Мишлен-подобный гид) |
| Связи | ← Фермы, мясокомбинаты, импорт вина; ← прачечная; → ресторанная сеть / франшиза; ↔ отели |

### 🍺 Бар / ночной клуб
- Входы: алкоголь (← пивоварня, винодельня, ликёро-водочный ← зерно/виноград), закуски, охрана, DJ/артисты.
- Лицензия на алкоголь; риски: штрафы, драки, полиция. Часы работы вечер–ночь.

### ☕ Кофейная обжарка
- Промзона/смешанное; CAPEX $200–800K (ростеры 15–120 кг).
- Входы: зелёное зерно (импорт: Бразилия, Колумбия, Эфиопия, Вьетнам), газ, упаковка.
- Выходы: **B2B — обжаренный кофе в кофейни (свои и чужие!), рестораны, офисы; B2C — розница в супермаркеты**.
- Ключевая механика **вертикальной интеграции**: своё зерно → своя обжарка → свои кофейни = маржа на всех уровнях + контроль качества.

### 🛒 Супермаркет
- 800–3 000 м²; CAPEX $1–5M. 3 000–15 000 SKU (в UI — категориями, не по одному).
- Входы: все потребительские товары от дистрибьюторов/фабрик, логистика, холодильное оборудование, энергия.
- Механики: **planogram-упрощение** (доля полки по категориям), **частная марка** (контракт с фабрикой — маржа выше), промо-акции, лояльность.
- Связи: точка сбыта для пищевых фабрик игроков; переговорная сила против поставщиков.

### 📱 Магазин электроники
- Входы: смартфоны, ноутбуки, ТВ, бытовая техника (← производство электроники / импорт из Азии).
- Риски: быстрое устаревание (товар теряет 2–5% стоимости в месяц), новые модели обнуляют спрос на старые.

### 👗 Бутик / магазин одежды
- Входы: одежда (← швейный цех / импорт), сезонные коллекции.
- Механика: **тренды** — каждый сезон тренд (цвет, стиль) генерируется; угаданный тренд = распродажа без скидок.

### 💪 Фитнес-клуб
- 500–5 000 м²; CAPEX $300K – $5M. Абонементы (подписная модель — стабильный кэшфлоу), персональные тренировки, бар.
- Сезонность: январь +40%, лето −20%. Отток абонентов (churn).
- Связи: → спортпит (производство), одежда; ← оборудование (машиностроение).

### 🔩 Автосервис / СТО
- Промзона/пригород; CAPEX $150–600K (подъёмники, диагностика).
- Входы: запчасти (← автопром/импорт), масла (← НПЗ), шины (← химзавод/резина).
- Выход: ремонт B2C, B2B (таксопарки, логистика, автодилеры). Механики дилерских контрактов.

### 🧹 Клининговая компания
- B2B-сервис: офисы, ТЦ, отели, клиники. Входы: химия, оборудование, персонал (много неквалифицированного).
- Контракты на 6–24 мес. Хороший «связующий» бизнес: обслуживает здания других игроков.

### 🛡 Охранное агентство
- B2B: охрана объектов (снижает риск краж, ограблений, вандализма у клиентов на 40–80%), инкассация для банков/ритейла.
- В PvP — защищает от **«грязных» действий** соперников (саботаж, промышленный шпионаж).

### 🏨 Мини-отель / гостиница
- 10–80 номеров; CAPEX $0,5–8M. Входы: прачечная, клининг, завтраки, ПО бронирования (← IT).
- Спрос: туризм + деловые поездки; сезонность; рейтинг на агрегаторах (← IT/медиа игрока).

### 🚚 Грузоперевозки
- Автопарк 3–50 грузовиков. Входы: дизель (← НПЗ), шины, ТО, водители, страховка.
- Выход: **логистика как услуга** для всех игроков/ИИ. Тарифы $/т·км. Типы ТС: фургон, рефрижератор, цистерна, тягач, самосвал.

### 📦 Склад / распределительный центр
- Промзона у трасс; 1 000–50 000 м². Сухой / холодильный / морозильный / опасные грузы.
- Выход: хранение (B2B, $/палето-место), кросс-докинг. Узел в цепочках поставок.

### 🛵 Курьерская служба / доставка еды
- Курьеры (пешие/вело/авто). Выход: доставка для ресторанов, магазинов, e-commerce. Комиссия 15–30%.
- В связке с IT-платформой → агрегатор доставки (тир III).

### 🌾 Ферма (растениеводство)
- Сельхозугодья 50–5 000 га. Культуры: пшеница, кукуруза, соя, подсолнечник, рапс, сахарная свёкла, картофель, овощи, хлопок.
- Входы: семена, удобрения (← химзавод ← газ), топливо, техника (← машиностроение), сезонные рабочие, вода.
- **Сезонный цикл:** посев → рост (погода, вредители) → сбор → продажа/хранение (элеватор). Урожайность зависит от технологий и погоды.
- Выход: зерно B2B (мельницы, комбикорм, экспорт, биотопливо).

### 🐄 Ферма (животноводство)
- Молочная (коровы → молоко), мясная (КРС, свиньи, птица), птицефабрика (яйца).
- Входы: корма (← ферма растениеводства / комбикорм), ветеринария, вода, энергия.
- Выход: молоко, мясо, яйца → молокозавод, мясокомбинат, рестораны.
- Риски: эпидемии скота (событие), санитарные запреты на экспорт.

### ☕ Плантация (кофе/какао/чай/фрукты)
- Только в климатических поясах. Цикл многолетний: от посадки до урожая 3–4 года (или покупка готовой плантации).
- Риски: засуха, заморозки, болезни (кофейная ржавчина), политические.
- Выход: зерно/листья → обжарки, шоколадные фабрики, чайные фабрики, экспорт.

### ⛏ Карьер (песок, щебень, глина)
- Первый бизнес добычи. Выход: стройматериалы → строительство, цементный завод, бетон.

### 🧵 Швейный цех
- Входы: ткань (← текстильная фабрика ← хлопок/синтетика ← НПЗ), фурнитура, швейные машины, швеи.
- Выход: одежда B2B (магазины, бренды), униформа (контракты для бизнесов — **у всех ваших бизнесов персонал в форме = +бренд**).

### 🛠 Механическая мастерская
- Металлообработка: детали на заказ для фабрик, ремонт оборудования. ← Сталь. → Машиностроение.

### 💻 IT-студия / веб-агентство
- Офис 50–500 м²; CAPEX $30–200K (компьютеры, лицензии).
- Персонал: программисты, дизайнеры, PM.
- Выход: **B2B-услуги разработки** (сайты, приложения для бизнесов игроков и ИИ: +онлайн-продажи, +лояльность). Проектная модель: контракты на N человеко-месяцев.
- Эволюция → софтверная компания (собственные продукты).

### 📣 Рекламное агентство
- Выход: **рекламные кампании для клиентов** (игроков и ИИ). Агентство закупает рекламу в медиа (ТВ, радио, наружка, интернет — у медиа-игроков!) и берёт комиссию + креатив.
- Навык креативщиков влияет на эффективность кампаний клиентов.
- Позволяет игроку видеть **бюджеты и стратегии клиентов** (информационное преимущество в PvP; утечка данных — риск репутации).

### 🏗 Строительная бригада / подрядчик
- Выход: строительство и ремонт для всех бизнесов (каждый CAPEX ремонта/строительства в игре — это заказ строителям!). Если все строители заняты — очереди и рост цен.
- Входы: цемент, сталь, кирпич, древесина, техника, рабочие.

### 🏠 Агентство недвижимости
- Комиссия за сделки с участками; аналитика рынка недвижимости (раскрывает «скрытые» данные о районах); управление арендой.

### ☀ Солнечная мини-станция
- Крыши/земля; CAPEX $50K – $2M. Выход: электроэнергия в сеть (по тарифу) или своим бизнесам (снижение затрат).

### 🌐 Интернет-провайдер (районный)
- Прокладка сети в районе; выход: подписки B2C/B2B. Входы: оборудование (← электроника), магистральный канал (← телеком-оператор).

### 🦷 Стоматология / лаборатория анализов
- Лицензия; высокая квалификация персонала; оборудование (← медтехника). Высокий чек, стабильный спрос.

### 💳 Микрофинансовая организация (МФО)
- Займы физлицам/малому бизнесу под высокий %. Риск невозврата = f(экономика). Регулятор может ограничить ставки.

### 📋 Страховой агент
- Продаёт страховки (свои — после лицензии страховой компании, или чужие за комиссию).

## 4.4 Тир III — Крупный бизнес / Промышленность

### 🍔 Ресторанная сеть / франшиза
- Объединяет ≥5 ресторанов/кофеен под одним **брендом**. Открывает механику **франшизы**: ИИ-предприниматели (или другие игроки!) открывают точки под вашим брендом, платят **паушальный взнос** ($20–50K) + **роялти** (4–8% выручки) и обязаны покупать у вашей центральной кухни/обжарки.
- Механики: стандарты качества (аудит франчайзи), центральная кухня, единые закупки (скидки за объём), национальная реклама.
- Риск: плохой франчайзи → удар по бренду.

### 🏭 Пищевая фабрика
Подтипы (каждый — отдельный модуль/рецепт):
| Подтип | Входы | Выходы |
|---|---|---|
| Мельница | Пшеница | Мука, отруби (→ корма) |
| Молокозавод | Сырое молоко, упаковка | Молоко, сыр, йогурт, масло |
| Мясокомбинат | Скот, специи, упаковка | Мясо, колбасы, полуфабрикаты |
| Кондитерская фабрика | Какао, сахар, мука, молоко | Шоколад, печенье, конфеты |
| Завод напитков | Вода, сахар, ароматизаторы, ПЭТ/алюминий | Газировка, соки, вода |
| Пивоварня | Ячмень/солод, хмель, вода, бутылки | Пиво |
| Винодельня | Виноград, бутылки, бочки | Вино (выдержка = рост качества со временем!) |
| Сахарный завод | Свёкла/тростник | Сахар, патока (→ этанол) |
| Маслоэкстракционный | Подсолнечник, соя, рапс | Масло, шрот (→ корма) |
| Завод полуфабрикатов/заморозки | Мясо, тесто, овощи | Пельмени, пицца, готовая еда |
- CAPEX $2–50M. Энергоёмкость, санитарные стандарты, сертификации для экспорта.

### 🏬 Сеть гипермаркетов
- Распределительные центры + собственная логистика + частная марка. Переговоры с поставщиками (отсрочка платежа 30–90 дней — **финансирование за счёт поставщиков**). Антимонопольный контроль при доле >35% в городе.

### 🛍 E-commerce / онлайн-магазин → маркетплейс
- Требует IT (платформа), склады, курьерскую доставку, платёжный сервис (← банк/финтех).
- Охват — вся страна. Маркетплейс: другие продавцы (игроки/ИИ) продают через вас, комиссия 5–20%.

### 🏥 Частная клиника
- Лицензия, врачи (дефицитный кадр), медтехника, фарма, лаборатория.
- Выход: B2C, страховые компании (контракты!), госзаказ (ОМС-аналог).
- Репутация критична; врачебные ошибки = суд + удар по бренду.

### 🏨 Сеть отелей
- Бренд, программа лояльности, центральное бронирование (← IT), классы 2★–5★. Связь с авиалиниями, турагентствами.

### 🚛 Логистическая компания (3PL)
- Мультимодальность: грузовики + склады + ж/д + (позже) море и авиа. **Сетевой эффект:** чем больше узлов, тем дешевле каждая доставка.
- Продаёт логистику как сервис всем игрокам. **Стратегический рычаг в PvP:** можно повысить тарифы сопернику (в рамках контрактов) или отказать в обслуживании (если нет антимонопольного запрета).

### 🚆 Ж/д-оператор
- Вагоны, локомотивы, доступ к путям (аренда у гос. оператора или своя ветка до рудника/порта).

### 🌾 Агрохолдинг
- Объединяет фермы + элеваторы + переработку + технику. Доступ к **фьючерсам на урожай** (хеджирование).

### ⛏ Угольная шахта / 🪵 Лесозаготовка
- Уголь → ТЭС, металлургия. Лес → лесопилка → мебель, стройка, бумага.
- Экологические ограничения, риск аварий.

### 🧪 Химический завод
- Входы: газ, нефтепродукты, соль, сера, электричество.
- Выходы: удобрения, бытовая химия, краски, кислоты, полимерное сырьё, резина.
- Опасное производство: экологические штрафы, аварии.

### ♻ Завод пластмасс / упаковки
- Входы: полимеры (← НПЗ/нефтехимия), бумага/картон (← целлюлозно-бумажный).
- Выход: упаковка для **всех** производителей и ритейлеров (стаканы для кофеен, бутылки для напитков, корпуса для электроники).

### 🧱 Цементный завод / производство стройматериалов
- Известняк + глина + энергия → цемент → бетон. Кирпич, стекло (песок + сода + газ), гипсокартон.
- Выход → строительство, девелопмент.

### 🪚 Лесопилка / ЦБК
- Лес → пиломатериалы (стройка, мебель) / целлюлоза → бумага, картон.

### 🏗 Девелопер
- Покупает землю, строит (через строителей), продаёт/сдаёт: ЖК, офисы, ТЦ, склады, отели.
- **Меняет город:** новый ТЦ создаёт торговый кластер; новый ЖК увеличивает население района.
- Ипотека (← банк) повышает спрос на жильё. Цикл недвижимости (пузыри!).

### 📡 Региональный телеком-оператор
- Мобильная связь (вышки, частоты — **аукцион лицензий на частоты**!), интернет.
- Подписочная модель, сетевые эффекты, технологические поколения (2G→3G→4G→5G→6G).

### 💻 Софтверная компания / SaaS
- Собственные продукты (см. каталог ПО в 06-operations): ERP, POS-системы, логистика, CRM, игры, антивирус, офисный пакет, операционные системы.
- Модель: разработка (R&D-очки × время) → релиз → подписки. Качество и баги, поддержка, обновления.
- **Ключевое:** продукты ПО дают **бонусы бизнесам покупателей** (POS +5% эффективности кассы, логистическое ПО −8% затрат на транспорт). Игрок-IT буквально делает экономику эффективнее и зарабатывает на всех.

### 📱 Производство электроники
- Сборка: смартфоны, ноутбуки, ТВ, бытовая техника, POS-терминалы, медтехника.
- Входы: чипы, экраны, аккумуляторы, корпуса (пластик/алюминий), платы.
- Конкуренция по поколениям продуктов; R&D критичен.

### 📻 Радио / локальное ТВ / 🎬 киностудия
- Медиа-площадки: продают **рекламное время** (рекламным агентствам и напрямую), набирают аудиторию через контент.
- Киностудия: проекты фильмов (бюджет, жанр, звёзды) → прокат (кинотеатры), ТВ-права, стриминг. Хиты/провалы.

### 🏭 ТЭС (газ/уголь) / 🌬 Ветропарк
- Продают электроэнергию на оптовый рынок региона. Газ/уголь — топливные затраты и выбросы; ветер — CAPEX и нестабильность выработки.

### 🏦 Региональный банк
- Лицензия (капитал от $50M, репутация ≥ 60). Депозиты (привлечение от домохозяйств/бизнесов под %) → кредиты (бизнесу, ипотека, потребительские).
- **Кредитует игроков и ИИ** (в т.ч. соперников). Регулятор: норматив достаточности капитала, резервы.
- Риск: кредитный, процентный, банковская паника (bank run).

### 🛡 Страховая компания
- Продукты: имущество бизнеса, автокаско, медицинское, жизнь, ответственность. Страховые премии сейчас — выплаты при событиях (пожар, авария, катастрофа) потом.
- Связь со всеми бизнесами игроков: страховка снижает удар событий. Катастрофы могут обанкротить страховщика без перестрахования.

### 💊 Производство дженериков
- Копии лекарств с истёкшим патентом. Входы: химические субстанции, упаковка. Лицензии, GMP-стандарты.

## 4.5 Тир IV — Корпорации и «империи»

### 🛢 Нефтегазовая компания *(эталон тира IV)*
| Модуль | Описание | CAPEX |
|---|---|---|
| Лицензия на блок | Аукцион государства или покупка у владельца | $5M – $2B |
| Геологоразведка | Сейсмика, разведочные скважины; результат — оценка запасов P10/P50/P90 | $10–200M |
| Добывающие скважины (суша) | 500–5 000 баррелей/день каждая | $5–30M/шт |
| Шельфовая платформа | 20 000–200 000 баррелей/день | $500M – $5B |
| Сланцевая добыча | Быстрое падение дебита, нужен постоянный бурильный цикл | $5–10M/скв. |
| Газовые месторождения + СПГ-завод | Сжижение для экспорта морем | $1–20B |
| Трубопровод | До НПЗ/порта; пересечение границ = соглашения | $1–10M/км |
| Нефтехранилище, терминал | | |
- **Себестоимость добычи** сильно различается: Ближний Восток $5–15/барр, суша $20–40, шельф $35–60, сланец $40–70. Цена нефти $10–150.
- **Решения:** темп добычи (быстро = истощение пласта, падение давления), инвестиции в повышение нефтеотдачи, хеджирование цены, ОПЕК-подобные картельные соглашения (PvP!).
- **Риски:** разлив (экокатастрофа, штрафы, бренд), национализация, санкции, падение цены, налог на добычу.
- **Связи:** → НПЗ → бензин/дизель/керосин/мазут/нафта → **вся логистика мира**, нефтехимия → пластик → упаковка/электроника/автопром; газ → ТЭС, химзаводы (удобрения → фермы), отопление.

### ⛽ НПЗ + сеть АЗС
- НПЗ: нефть → бензин (45%), дизель (25%), керосин (10%), мазут (10%), нафта/сжиженный газ (10%) — пропорции меняются глубиной переработки (апгрейды: крекинг, риформинг).
- Сеть АЗС: B2C-точки продажи топлива + магазин при АЗС (ритейл).

### ⚙ Металлургический комбинат
- Железная руда + коксующийся уголь + энергия → чугун → сталь. Электродуговые печи — из металлолома (+ВИЭ = «зелёная сталь» премиум).
- Алюминиевый завод: бокситы → глинозём → алюминий (крайне энергоёмко → строится у ГЭС).
- Медеплавильный, литейный. Выход → автопром, стройка, судостроение, машиностроение, электроника.

### ⛏ Горнорудная компания
- Железо, медь, золото, литий, никель, редкоземельные, уран. Открытый/подземный способ. Обогатительная фабрика.

### 🚗 Автопроизводитель
- Модели: компакт, седан, внедорожник, грузовик, автобус, электромобиль, спорткар, люкс.
- Входы: сталь, алюминий, пластик, резина/шины, стекло, двигатели (собственные или покупные), электроника, чипы, аккумуляторы (EV).
- **Конструктор модели**: платформа × двигатель × комплектация × дизайн → себестоимость, качество, привлекательность для сегментов.
- Дилерская сеть (автосалоны тира II — свои или франчайзи), сервис (автосервисы), автокредиты (← банк).

### 🚢 Морское судоходство / судоверфь
- Танкеры, балкеры, контейнеровозы, газовозы. Фрахтовые ставки (индекс, волатильны). Порты, каналы, пираты (событие).
- Судоверфь строит суда (сталь, двигатели) — для себя и на продажу.

### ✈ Авиалиния
- Лицензия, флот (лизинг/покупка самолётов), слоты в аэропортах, маршруты (туризм, бизнес, грузы).
- Входы: керосин (← НПЗ — 30% затрат!), пилоты, ТО, питание (← кейтеринг).
- Связи с отелями, туризмом; перевозка премиальных грузов (электроника, цветы, фарма).

### 🔬 Полупроводники (фабрика чипов)
- **Самый дорогой и технологичный бизнес:** CAPEX $1–20B, техпроцессы (180нм → 3нм — дерево R&D).
- Входы: кремниевые пластины (← кремний ← кварц + энергия), сверхчистые газы/химия, фотолитографическое оборудование (← импорт от «внешнего мира» или своё производство тира V), ультрачистая вода, огромное потребление энергии.
- Выход → вся электроника, автопром, датацентры, телеком. **Стратегический ресурс** (санкции, господдержка).

### ☁ Облако / датацентры
- Серверы (← электроника), энергия (30–50% затрат!), охлаждение, связь.
- Выход: вычисления как сервис для SaaS-компаний, соцсетей, ИИ, банков. Расположение у дешёвой энергии и холодного климата.

### 🌍 Соцсеть / поисковик / стриминг
- Модель: пользователи (сетевые эффекты, бесплатный сервис) → рекламные доходы / подписки.
- Это **рекламный канал** для всех других бизнесов: таргетированная реклама эффективнее ТВ.
- Данные пользователей → преимущество в маркетинге; регуляция приватности, антимонопольные дела.

### 🏦 Инвестбанк / биржа / хедж-фонд
- Инвестбанк: андеррайтинг IPO и облигаций (других игроков!), M&A-консалтинг (комиссия 1–3% от сделки), трейдинг.
- Биржа: открытие национальной биржи — комиссия с каждой сделки.
- Хедж-фонд: управление капиталом с плечом, шорты (можно шортить акции соперника!).

### ⚛ АЭС / 🌊 ГЭС / ⚡ Энергосеть
- АЭС: CAPEX $5–15B, строительство 5–8 лет, дешёвая стабильная энергия, топливо (← уран ← обогащение), риск аварии (катастрофическое событие), лицензия.
- ГЭС: только на крупных реках; огромный CAPEX, бесконечный ресурс, сезонность.
- Энергосеть: ЛЭП, трансформаторы, распределение — естественная монополия (тарифы регулирует государство).

### 💊 Фармкорпорация / биотех
- R&D лекарств: стадии (доклиника → фаза I → II → III → одобрение), каждая с вероятностью провала (90% кандидатов проваливаются). 8–12 игровых лет.
- Успешный препарат: **патент** на 20 лет → сверхприбыль. После — дженерики (в т.ч. игроков) обрушивают цену.
- Вакцины (событие пандемии!), госзакупки, ценовое регулирование.

### 📺 Медиахолдинг
- Объединяет ТВ, радио, издательства, киностудии, онлайн-СМИ. **Влияние на общественное мнение:** может поднимать/топить репутацию компаний (в т.ч. соперников — PvP-механика «медиакампании»), влиять на выборы (политика).

### 🛰 Национальный телеком / спутниковая связь
- Магистральные сети, подводные кабели, спутники (← аэрокосмос). Предоставляет каналы связи всем провайдерам.

## 4.6 Тир V — Мегапроекты (эндгейм)

Мегапроекты — многолетние проекты стоимостью $20B–$500B, требующие кооперации нескольких отраслей. Дают уникальные глобальные бонусы и/или условия победы.

| Мегапроект | Требования | Эффект |
|---|---|---|
| 🚀 **Космическая программа** | Аэрокосмический завод, полупроводники, металлургия (титан), R&D «Ракетостроение» ур. 5 | Запуск спутников (глобальная связь, ГЛОНАСС/GPS-сервис, спутниковая съёмка — раскрывает разведданные ресурсов), космический туризм, далее — добыча на астероидах (новые сверхредкие ресурсы) |
| 🤖 **ИИ-лаборатория (AGI-проект)** | Датацентры мощностью N, полупроводники 5нм, 2 000+ data scientists | Глобальный бонус производительности всех ваших бизнесов +15–30%; продажа ИИ-сервисов; регуляторные и общественные риски |
| 🏙 **Умный мегаполис** | Девелопер, энергетика, телеком, логистика, IT | Новый город на карте (вы — владелец земли): поток налогов, аренды, монополия на услуги на старте |
| ⚡ **Термоядерный синтез** | АЭС, R&D «Термояд» ур. 5, сверхпроводники | Почти бесплатная энергия → крах цен на нефть/газ (если вы — конкурент нефтяника, это оружие!) |
| 🌐 **Глобальная спутниковая сеть интернета** | Космическая программа + телеком | Интернет везде; доходы с каждой страны |
| 🧬 **Продление жизни / биотех-прорыв** | Фарма + ИИ | Огромный рынок, этические события |
| 🚄 **Трансконтинентальная магистраль (гиперпетля / высокоскоростная ж/д)** | Стройка, сталь, энергетика | Революция логистики на континенте; плата за проезд |
| 🌊 **Новый морской канал / мега-порт** | Стройка, судоходство, политическое соглашение | Изменение мировых торговых маршрутов, плата за проход |
| 🏦 **Мировая резервная платёжная система / цифровая валюта** | Банк, биржа, IT, политическое влияние | Комиссия с мировых транзакций; антиглобалистские события |
