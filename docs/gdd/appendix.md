# Приложения

## A.1 Глоссарий

| Термин | Значение |
|---|---|
| **Бизнес-юнит** | Конкретный объект (кофейня №17, НПЗ «Роттердам-1») |
| **Компания** | Юрлицо, владеющее юнитами; может быть дочерней |
| **Холдинг** | Головная компания игрока |
| **Рецепт** | Правило преобразования входов в выходы в бизнесе |
| **Спот** | Рынок немедленной покупки/продажи по текущей цене |
| **Контракт** | Двустороннее соглашение, исполняемое системой |
| **ОВ (Очки Внимания)** | Лимит юнитов под ручным управлением игрока без менеджеров |
| **ОВл (Очки Влияния)** | Политический ресурс в стране |
| **Престиж** | Мета-ресурс статуса игрока |
| **Индекс Империи** | Сводная метрика успеха в PvP |
| **Внешний мир** | Агрегированный агент импорта/экспорта по мировым ценам |
| **Фоновые бизнесы** | Агрегированные мелкие ИИ-конкуренты |
| **Директор событий** | Система, генерирующая события с учётом драматургии |
| **Туман войны** | Скрытость данных соперников |
| **Тик** | Шаг симуляции = 1 игровой час |
| **CAPEX / OPEX** | Капитальные / операционные затраты |
| **EBITDA** | Прибыль до процентов, налогов и амортизации |
| **BATNA** | Лучшая альтернатива переговорному соглашению (цена резервации) |

## A.4 Пример данных события (YAML)

```yaml
id: global_chip_shortage
title: { ru: "Глобальный дефицит чипов", en: "Global Chip Shortage" }
class: industry
trigger:
  earliest_year: 2015
  conditions:
    - world_demand_growth: { good: processors, gt: 0.15 }
    - or: [ random_per_year: 0.05 ]
duration_months: [12, 24]
effects:
  - { type: production_capacity, good: [processors, memory, microcontrollers], multiplier: 0.7 }
  - { type: spot_price_shock, good: microcontrollers, multiplier: 1.8 }
  - { type: news, priority: high }
consequences_hint:
  ru: "Автопроизводители и производители электроники сокращают выпуск. Цены на б/у авто растут."
```

## A.5 Формулы — краткая сводка

| Что | Формула |
|---|---|
| Доля продавца | `Share_j = exp(U_ij) / (Σ_k exp(U_ik) + exp(U_out))` |
| Полезность | `U = β_p·ln(P) + β_q·Q + β_b·Brand + β_d·Dist + β_w·Queue + β_l·Loyalty` |
| Качество выхода | `Q = clamp(w_in·Q_in + w_eq·Q_eq + w_st·Q_staff + w_t·Tech, 1, 5)` |
| Спотовая цена (тонкий рынок) | `P' = P·(1 + k·(D − S)/S)`, лимит ±10%/день |
| Мировой якорь | `P_import = P_world·(1+markup) + transport + tariff` |
| Узнаваемость | `ΔA = (1 − A)·(1 − e^(−k·GRP·creative))`, затухание 2–5%/мес |
| Ставка кредита | `r = r_CB + spread(rating) + term_premium` |
| ЦБ (Тейлор) | `i = r* + π + 0.5(π − π*) + 0.5·gap` |
| Цена акции | `P' = P + α(Fair − P) + Sentiment + News + OrderFlow + noise` |
| Индекс Империи | `0.5·NetWorth + 0.2·Revenue + 0.15·Influence + 0.1·Prestige + 0.05·Reputation` |
| Логистика | `Cost = Σ tariff·t·km·fuelCoef + handling + customs + insurance` |
