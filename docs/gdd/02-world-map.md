# 02. Карта мира и локации

## 2.1 Общая структура

Мир — 3D-глобус Земли с реальными очертаниями континентов (данные Natural Earth, упрощённые). Иерархия:

```
Мир
 └─ Макрорегион (8): Северная Америка, Латинская Америка, Западная Европа, Восточная Европа и СНГ,
 │                    Ближний Восток и Северная Африка, Африка южнее Сахары, Южная и Центральная Азия,
 │                    Восточная Азия и Океания
     └─ Страна (≈60 играбельных + «прочий мир» как агрегированный рынок)
         └─ Город (≈250 играбельных; 3–15 на крупную страну)
             └─ Район (4–30 на город; генерируются по шаблонам)
                 └─ Участок (lot) — конкретная точка, где стоит бизнес
         └─ Ресурсные зоны вне городов: нефтяные поля, рудники, сельхозугодья, леса, побережья, порты
```

### Масштабирование карты (уровни зума)

| Уровень | Что видно | Взаимодействие |
|---|---|---|
| **Орбита** | Глобус, страны, тепловые карты (ВВП, спрос, ваша доля), торговые маршруты | Выбор страны, глобальные отчёты, мировые события |
| **Страна** | Города-маркеры, ресурсные зоны, дороги/ж/д/порты | Покупка ресурсных участков, выбор города, законы страны |
| **Город** | Районы с цветовой индикацией (престиж, трафик, аренда), иконки бизнесов | Аналитика районов, выбор района |
| **Район** | Процедурные кварталы, отдельные здания, участки (свободные/занятые/на продажу) | **Клик на здание → открыть/купить бизнес**, видеть конкурентов рядом |
| **Улица** (опц.) | Детализированное здание, вывеска, поток пешеходов (частицы) | Кастомизация вывески/фасада, визуальная обратная связь |

## 2.4 Районы

Каждый город генерируется из набора **архетипов районов**:

| Архетип | Аренда | Пешеходный поток | Доход жителей | Подходит для |
|---|---|---|---|---|
| Деловой центр (CBD) | ★★★★★ | ★★★★★ днём, ★ ночью | ★★★★ | Кофейни, рестораны ланча, банки, офисы |
| Исторический центр | ★★★★ | ★★★★★ | ★★★ | Туризм, рестораны, бутики, отели |
| Престижный жилой | ★★★★ | ★★ | ★★★★★ | Премиум-магазины, клиники, фитнес |
| Спальный район | ★★ | ★★★ утро/вечер | ★★ | Супермаркеты, пекарни, аптеки, прачечные |
| Студенческий | ★★ | ★★★★ | ★ | Фастфуд, кафе, копицентры, бары |
| Торговый кластер (ТЦ) | ★★★ | ★★★★ | ★★★ | Ритейл, фудкорты, кино |
| Промзона | ★ | ★ | ★ | Фабрики, склады, автосервисы |
| Порт/логистика | ★★ | ★ | ★ | Склады, логистика, НПЗ (если у моря) |
| Пригород/коттеджи | ★★ | ★ | ★★★★ | Автосалоны, строительные гипермаркеты |
| Технопарк | ★★★ | ★★ | ★★★★ | IT, R&D, полупроводники, биотех |

### Динамика районов
- **Джентрификация:** если в спальном районе открывается много кофеен, фитнесов, премиум-магазинов — индекс престижа растёт, аренда растёт, состав жителей меняется (+доход, –население).
- **Упадок:** закрытие бизнесов, рост преступности → падение аренды, поток уменьшается.
- Игрок-девелопер может **целенаправленно** менять районы (строить ЖК, ТЦ, парки).

## 2.5 Участки (Lots)

Участок — базовая единица размещения бизнеса.

| Поле | Пример | Описание |
|---|---|---|
| `id` | `MSK-ARB-0142` | Уникальный ID |
| Тип | Помещение в здании / Отдельное здание / Земля / Ресурсный участок | |
| Площадь | 40 м² – 500 000 м² | Ограничивает тип и масштаб бизнеса |
| Зонирование | Коммерция / Жильё / Промышленность / Смешанное / Сельхоз / Добыча | Разрешённые бизнесы |
| Пешеходный трафик | 0–10 000 чел/день | Ключ для B2C |
| Видимость | 0–100 | Угол, первая линия, витрина |
| Доступ для грузовиков | да/нет, тоннаж | Для поставок |
| Парковка | мест | Важно для автосервисов, ТЦ |
| Владелец | Город / ИИ / Игрок | |
| Форма владения | Аренда / Собственность | |
| Цена аренды | $/мес | Пересматривается раз в год |
| Цена покупки | $ | Зависит от района и тренда |
| Состояние | 0–100 | Требует ремонта при низком |

### Аренда vs. покупка
- **Аренда:** низкий порог входа, ежемесячный платёж, риск повышения при продлении (раз в 1–3 года), риск выселения, если владелец (в т.ч. игрок-соперник!) решит не продлевать.
- **Покупка:** большие вложения, но актив растёт в цене, служит залогом для кредитов, можно сдавать.
- **PvP-механика:** соперник может купить здание, где вы арендуете, и поднять аренду при продлении (в пределах закона страны — лимит роста аренды).

## 2.7 Транспортная сеть на карте

- **Дороги:** соединяют все города страны; межстрановые — по реальным коридорам.
- **Железные дороги:** не во всех странах; дешевле грузовиков на дальние расстояния.
- **Морские порты:** ~120 портов; морские маршруты по реальным путям (Суэц, Панама, Малакка, мыс Доброй Надежды). Узкие места могут быть закрыты событиями.
- **Аэропорты:** дорогая быстрая доставка (электроника, фарма, цветы).
- **Трубопроводы:** строятся игроками (нефть, газ). Пересечение границ требует межгосударственного соглашения.
- **ЛЭП:** для энергетических компаний; продажа электроэнергии в соседние регионы.

Маршруты визуализируются на глобусе дугами/линиями с анимированными частицами (корабли, грузовики, самолёты как инстансы).

## 2.8 Тепловые карты (Map Overlays)

Переключаемые слои на любом уровне зума:
- Спрос на выбранный товар/услугу
- Насыщенность конкурентами
- Аренда / стоимость земли
- Доход населения
- Пешеходный трафик
- Ваша доля рынка
- Ваши активы и цепочки поставок
- Риски (политические, климатические, преступность)
- Загрязнение / экологический рейтинг
- Влияние игроков (PvP: кто доминирует где)
