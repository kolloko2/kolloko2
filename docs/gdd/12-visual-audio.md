# 12. Визуал, звук и рендеринг на Three.js

## 12.1 Арт-стиль

**«Стилизованный реализм / диорама»** — чистая low-poly/mid-poly геометрия, мягкий свет, приглушённая палитра с яркими акцентами для данных (цвета игроков, тепловые карты). Ориентиры: Mini Motorways, Cities: Skylines в режиме карты, Townscaper, Google Earth в «плоском» стиле, инфографика Bloomberg.

Причины:
- Производительность в браузере.
- Читаемость данных поверх мира (карта — это интерфейс).
- Не стареет визуально.

### Цветовые коды
- Каждый игрок — свой цвет (8 цветов, безопасных для дальтоников) + узор для наложений.
- ИИ-корпорации — нейтральные оттенки.
- Состояние: зелёный (хорошо), жёлтый (внимание), красный (проблема) — с дублированием иконками.

## 12.2 Уровни детализации мира

| Уровень зума | Что рендерится | Техника |
|---|---|---|
| **Орбита** (высота > 3 000 км) | Сфера Земли: альбедо-текстура (стилизованная), рельеф (normal map), океан с шейдером (френель, блики), атмосфера (rim-шейдер), облака (опционально), ночные огни городов (на тёмной стороне — растут по мере развития экономики!), границы стран (линии на сфере), маркеры городов | `SphereGeometry` высокой детализации или кубосфера; `ShaderMaterial`; линии — `Line2`/`LineSegments2`; маркеры — `InstancedMesh`/спрайты |
| **Страна** (300–3 000 км) | + дороги/ж/д (линии), ресурсные зоны (полигоны-оверлеи), торговые маршруты (дуги с частицами), иконки активов | Проекция геоданных на сферу; дуги — `TubeGeometry`/линии по большим окружностям; частицы — instanced |
| **Город** (10–300 км) | Переход от сферы к **локальной плоской карте** (tangent plane) с плавной анимацией; районы — экструдированные полигоны с цветом-оверлеем; агрегированные «облака» зданий | `ExtrudeGeometry` по районам; кросс-фейд между глобусом и тайлом города |
| **Район** (< 10 км) | Процедурные кварталы: улицы, здания (блоки из модульного кита), участки; бизнесы игроков — с вывесками/цветом; пешеходы/машины как частицы | `InstancedMesh` для зданий (тысячи), `BatchedMesh` для вариаций; LOD; frustum culling |
| **Улица** (опц.) | Детализированная модель здания игрока, витрина, вывеска (текстура с названием бренда — генерируется `CanvasTexture`) | glTF-модели, Draco-сжатие |

### Переход «глобус → город»
1. При зуме ниже порога камера «прилипает» к точке, сфера плавно заменяется плоским тайлом (локальная проекция ENU — east-north-up).
2. Тайл города загружается асинхронно (геометрия районов генерируется процедурно по сиду + метаданным города; кешируется в IndexedDB).
3. Кросс-фейд 300–500 мс; во время перехода — анимация облаков/тумана, скрывающая подмену.

## 12.3 Процедурная генерация городов
- Вход: метаданные города (население, архетипы районов, реальное положение, наличие моря/реки) + сид.
- Шаги: границы районов (диаграмма Вороного, подстроенная под береговую линию) → сеть улиц (L-system/«tensor field» упрощённо: сетка в центре, органика на окраинах) → кварталы → участки → здания из модульного кита по архетипу района (высотки в CBD, малоэтажка в спальных, ангары в промзоне).
- Генерация детерминирована (сид) — одинакова у всех клиентов, не передаётся по сети.
- Изменения от игроков (построенные ТЦ, ЖК, снесённые здания) хранятся как **дельты** и применяются поверх.

## 12.4 Визуальная обратная связь экономики
- **Поток клиентов:** частицы-пешеходы, текущие к бизнесам (плотность = поток).
- **Логистика:** грузовики по улицам, корабли по морским маршрутам, самолёты по дугам (instanced, анимация на GPU через vertex shader по параметру времени).
- **Деньги:** всплывающие «+$» над прибыльными точками (опционально, отключаемо).
- **Рост:** ночные огни городов на глобусе ярче там, где экономика растёт; строительные краны на стройплощадках.
- **Проблемы:** пульсирующие иконки над проблемными юнитами.
- **Загрязнение:** дымка над промзонами (шейдер тумана с плотностью от уровня загрязнения).
- **День/ночь:** терминатор на глобусе в реальном времени (по игровому времени); в районе — освещение меняется, вывески светятся ночью.
- **Погода/сезоны:** снег на карте зимой в северных городах (текстурный блендинг).

## 12.5 Производительность (бюджеты)

| Метрика | Цель (средний ноутбук, интегрированная графика) |
|---|---|
| FPS | 60 на орбите, ≥ 45 в районе |
| Draw calls | < 300 |
| Треугольники | < 1,5M на кадр |
| Память GPU | < 1 ГБ |
| Время первой загрузки | < 10 с до глобуса (≈15 МБ стартовых ассетов) |
| Размер ассетов всего | < 200 МБ (стриминг по требованию) |

**Техники:**
- `InstancedMesh` / `BatchedMesh` для всех повторяющихся объектов.
- LOD (`THREE.LOD`) + impostors (билборды) для дальних зданий.
- Frustum culling, occlusion — грубая (по кварталам).
- Текстурные атласы, KTX2/Basis сжатие текстур, Draco/meshopt для геометрии.
- Тени: одна каскадная (CSM) только на уровне района; на орбите — без теней (baked AO).
- Пост-обработка минимальная (FXAA/SMAA, лёгкий bloom для огней) с переключателем качества.
- **WebGPU-рендерер** (`three/webgpu`) как опция с fallback на WebGL2.
- UI — DOM/React поверх canvas (не в WebGL), чтобы не нагружать рендер и использовать доступность браузера.
- Тяжёлая клиентская логика (генерация городов, pathfinding частиц) — в **Web Workers**; геометрия передаётся через Transferable/SharedArrayBuffer.

### Настройки графики
Низкие / Средние / Высокие / Ультра + ручные: разрешение рендера (50–100%), тени, количество частиц, детализация зданий, облака, атмосфера, пост-эффекты, ограничение FPS (экономия батареи).

## 12.6 Звук и музыка

### Музыка
- **Адаптивный саундтрек** (горизонтальное ресеквенирование + вертикальные слои): спокойный lo-fi/jazz/ambient-электроника на тирах I–II → оркестрово-электронный «корпоративный» на тирах III–V.
- Слои по состоянию: напряжение (кризис, враждебное поглощение) — добавляет перкуссию/басы; процветание — светлые слои.
- Стилистические темы эпох (2000-е, 2010-е, 2020-е) — тонкие отсылки в аранжировке.

### Звуковые эффекты
- UI: мягкие клики, «звон кассы» при крупной сделке, тревожный тон критических уведомлений.
- Мир (позиционный звук при зуме в район): гул города, кофемашина у кофейни, шум фабрики, порт (гудки судов), трафик.
- Глобус: тихий «космический» эмбиент, ветер атмосферы при зуме.

### Голос
- Короткие реплики советников (опционально, ключевые события).
- Новостной диктор для крупных мировых событий (озвучка на RU/EN).

### Техника
- Web Audio API (через Howler.js или `THREE.PositionalAudio`), сжатие Opus/AAC, стриминг музыки.
- Микшер: мастер, музыка, эффекты, мир, UI, голос.
