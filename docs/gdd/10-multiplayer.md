# 10. Мультиплеер: кооператив и PvP

## 10.1 Обзор режимов

| Режим | Игроки | Длительность | Суть |
|---|---|---|---|
| **Кампания** (соло) | 1 | 10 сценариев × 1–3 ч | Обучение + сюжетные цели |
| **Песочница** (соло) | 1 | Бесконечно | Свободная игра с ИИ-магнатами |
| **Холдинг** (кооп) | 2–4 | 2–6 ч, сохраняемо | Один общий холдинг, разделение ролей |
| **Союз** (кооп) | 2–4 | 2–6 ч | Отдельные компании, общая победа против ИИ-магнатов и кризисов |
| **Свободный рынок** (PvP FFA) | 2–8 | 60–180 мин | Каждый сам за себя |
| **Корпоративные войны** (PvP команды) | 2v2, 3v3, 4v4 | 90–180 мин | Команды-холдинги |
| **Рецессия** (PvP «королевская битва») | 4–8 | 45–60 мин | Экономика постепенно сжимается; банкроты выбывают; последний выживший побеждает |
| **Блиц** (PvP) | 2–4 | 20–30 мин | Старт с тира II, ускоренное время, одна страна |
| **Постоянный мир** (будущее, post-launch) | 50–500 | Сезон 4–8 недель | Асинхронная MMO-экономика, оффлайн-режим под управлением менеджеров |

## 10.2 Кооператив «Холдинг»

### 10.2.1 Общий холдинг
- Один общий баланс, общие активы, общие технологии.
- Каждый игрок занимает **роль** с особыми правами и бонусами (роли можно менять по голосованию, или включить режим «все могут всё»).

| Роль | Права | Бонус |
|---|---|---|
| **CEO (Генеральный директор)** | Финальное слово в спорах, M&A, стратегические решения, распределение бюджетов между ролями | +ОВ на всю компанию, +Престиж |
| **COO (Операционный)** | Управление бизнес-юнитами, производство, логистика, найм | +5% эффективность операций |
| **CFO (Финансовый)** | Кредиты, облигации, биржа, налоги, бюджеты, хеджирование | −0,5% ставки по кредитам, видит прогнозы рынков точнее |
| **CMO (Маркетинг/продажи)** | Бренды, реклама, ценообразование, переговоры с клиентами | +10% эффективность рекламы |
| **CTO (Технологии)** | R&D, IT-продукты, технологии, патенты | +10% R&D |
| **Региональный директор** (для 4+ игроков) | Полные права в своём регионе/отрасли | +ОВ в регионе |

### 10.2.2 Бюджеты и запросы
- CEO/CFO распределяют **бюджеты** по ролям/регионам. Трата сверх бюджета требует **запроса** (уведомление, одобрение одним кликом).
- Крупные решения (> 20% капитала) — **голосование** (по умолчанию простое большинство, CEO — решающий голос при ничьей).
- **Пинги на карте** («открой здесь склад!»), заметки, общий чат, голосовой чат.

### 10.2.3 Кооп-цели
- Сценарные цели (например, «Выйти на IPO до 2008», «Стать №1 по выручке в 3 отраслях», «Пережить кризис 2008 без банкротства дочек»).
- **Совместная оценка**: общий счёт + личная статистика вклада (кто сколько прибыли принёс) — для мотивации без конфликта.

### 10.2.4 Кооп «Союз»
- Каждый игрок — отдельная компания, но цель общая: обойти ИИ-магнатов по суммарной капитализации.
- Межигровые контракты с льготами (без комиссий), можно передавать деньги, общие технологии по соглашению.
- Мягкое соперничество: личный рейтинг внутри команды.

## 10.3 PvP «Свободный рынок»

### 10.3.1 Настройки лобби
| Параметр | Варианты |
|---|---|
| Карта | Весь мир / регион (Европа, Азия, Америки) / одна страна |
| Стартовая эпоха | 1980 / 2000 / 2025 / вымышленная |
| Стартовый капитал | $50K (стандарт) / $1M / $50M / асимметричный (гандикап) |
| Скорость | Фиксированная ×1–×8 / голосование |
| ИИ-конкуренты | Нет / мало / стандарт / много; сложность |
| Длительность / условие победы | См. 10.3.2 |
| «Жёсткий режим» | Саботаж, шпионаж, коррупция — вкл/выкл |
| Оценка сделок | Показывать / скрыть |
| Туман войны | Полный (данные соперников только через разведку) / частичный / открытый |
| Случайные события | Мягкие / стандарт / хаос |
| Банкротство | Выбывание / перезапуск с малым капиталом / помощь государства |
| Союзы | Разрешены / запрещены / фиксированные команды |
| Тактические паузы | 0–5 на игрока |

### 10.3.2 Условия победы (выбираются хостом, можно комбинировать)
1. **Капитализация:** первым достичь $X (например, $100B) стоимости компании (рыночная для публичных / оценка для частных) + личного капитала.
2. **Таймер:** победитель — с наибольшим **Индексом Империи** на дату окончания (например, 2015 год).
3. **Монополия:** контролировать ≥ 50% мирового рынка в N отраслях (из выбранного списка).
4. **Поглощение:** приобрести контроль (> 50%) над холдингами всех соперников или вынудить их к банкротству.
5. **Престиж:** накопить N очков Престижа (мегапроекты, благотворительность, статусные активы).
6. **Мегапроект:** первым завершить выбранный мегапроект тира V (например, космическую программу).

### 10.3.3 Индекс Империи (основная метрика)
```
Индекс = 0.50 × Чистая_стоимость_активов (капитализация холдинга × доля игрока + личный капитал)
       + 0.20 × Нормализованная_выручка (скользящая годовая)
       + 0.15 × Рыночное_влияние (Σ долей рынка, взвешенных по размеру рынков)
       + 0.10 × Престиж
       + 0.05 × Деловая_репутация
```
Веса — настраиваемы в лобби. Индекс виден всем (в тумане войны — с погрешностью ±10%).

### 10.3.4 Взаимодействие между игроками в PvP
**Мирные:**
- Торговля товарами и услугами, контракты, совместные предприятия, займы.
- Инвестиции в акции друг друга.
- Альянсы, картели, раздел рынков.

**Конкурентные (легальные):**
- Ценовые войны, борьба за локации и кадры.
- Эксклюзивы, блокировка каналов сбыта.
- Враждебные поглощения, скупка облигаций, шорты.
- Лоббирование против интересов соперника.
- Отказ в обслуживании (если вы монополист инфраструктуры — с риском антимонопольного дела).

**«Грязные» (только Жёсткий режим):**
- Шпионаж, саботаж, кибератаки, медиа-компромат, подкуп.

### 10.3.5 Антизадротские и антиснежковые механики
Чтобы лидер не убегал безвозвратно, а отстающие имели шанс:
- **Антимонопольный регулятор** — естественный тормоз для лидера.
- **Убывающая отдача** от масштаба после определённого порога (управленческая сложность, бюрократия).
- **Директор событий** немного чаще направляет кризисы на перегретые сектора/лидера (настраиваемо, по умолчанию мягко).
- **Ребалансирующий интерес ИИ:** ИИ-консолидаторы охотнее объединяются против лидера; ИИ-банки охотнее кредитуют отстающих.
- **«Тёмная лошадка»:** Индекс имеет компоненту роста (последние 2 года) для таймерной победы — опционально.
- **Не снежный ком, а взаимозависимость:** лидер нуждается в поставщиках/покупателях, которыми могут быть отстающие — переговорная сила.

### 10.3.6 Выбывание и банкротство
- По умолчанию: банкрот получает «второй шанс» — стартует заново с $50K (без возможности победы, но может быть «кингмейкером» и сохраняет рейтинг участия).
- Режим «Рецессия» — выбывание окончательное; выбывший становится наблюдателем или «теневым инвестором» (может торговать акциями на остатки).

## 10.4 PvP «Корпоративные войны» (команды)
- Команды по 2–4 игрока; внутри команды — кооп-правила (общий холдинг или союз — по выбору).
- Победа команды по Индексу/поглощению.
- Командная коммуникация (приватный чат/голос), видимость данных друг друга.

## 10.5 Режим «Рецессия»
- Старт: все игроки в одной стране/регионе, тир I–II.
- Каждые N игровых месяцев «экономика сжимается»: ↑ ставки ЦБ, ↓ спрос, кредитное сжатие, закрываются регионы (как «зона» в battle royale — рынки становятся недоступны / нерентабельны).
- Банкроты выбывают; их активы — аукцион для выживших.
- Финальная фаза: 2–3 игрока в глубокой депрессии, борьба за последний живой рынок.

## 10.6 Лобби, матчмейкинг, рейтинг

- **Приватные лобби** по коду/ссылке (основной сценарий — «с друзьями»).
- **Публичные лобби** со списком.
- **Рейтинговый матчмейкинг** (post-launch) для PvP-режимов Блиц и Свободный рынок: Elo/Glicko-2, сезоны, лиги.
- **Drop-in/drop-out в кооперативе:** игрок может подключиться к идущей игре (взяв вакантную роль), отключившийся — заменяется ИИ-менеджером по политике.
- **Реконнект** в PvP: 5 минут на возвращение, далее — ИИ-автопилот (консервативный).
- **Сохранения** мультиплеерных сессий на сервере; продолжение в любое время, когда все (или хост + большинство) онлайн.
- **Наблюдатели и стримеры:** режим наблюдателя с задержкой; «режим стримера» скрывает коды лобби.

## 10.7 Коммуникация
- Текстовый чат: общий, альянс/команда, приватный.
- Голос: встроенный WebRTC (опционально), интеграция с Discord (Rich Presence + приглашения).
- Пинги на карте, эмоции, быстрые фразы («Хочу купить нефть», «Предлагаю альянс»).
- **Лента новостей мира** (внутриигровые СМИ): крупные сделки игроков, банкротства, поглощения — генерирует истории и «разговоры за столом».

## 10.8 Синхронизация времени в мультиплеере
- Серверно-авторитетная симуляция идёт непрерывно; клиенты получают снапшоты и дельты.
- Скорость: минимальная из голосов или фиксированная хостом.
- **Асимметрия внимания:** чтобы игрок не проигрывал, пока торгуется в переговорном окне, существуют **политики автоматизации** (менеджеры) и **уведомления-триггеры** («если цена зерна > $4 — сообщи / автоматически перейди на другого поставщика»).
- Тактические паузы — ограниченные.
