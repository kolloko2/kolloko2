# План разработки игры «МАГНАТ: Империя»

Документ описывает, **как именно** превратить ГДД (`docs/gdd/`) в работающую игру: этапы, задачи, архитектуру, критерии готовности. Принцип: **сначала экономика, потом графика**. Пока игра работает на реальной 2D-карте (Leaflet + OpenStreetMap) с текстом и иконками; 3D на Three.js — отдельный поздний этап, который заменит только слой отображения, а не логику.

---

## 0. Ключевые архитектурные решения (принимаем сразу)

| Решение | Почему |
|---|---|
| **Симуляция — чистый JS-модуль без DOM** (`game/src/sim/`) | Один и тот же код запускается в браузере (соло), в Node (тесты, headless-балансировка) и на сервере (мультиплеер) |
| **Все действия игрока — команды** (`applyCommand(state, cmd)`) | Готовность к мультиплееру: клиент шлёт команды, сервер применяет. Реплеи, отладка |
| **Детерминированный ГСЧ в состоянии** (`state.rng`) | Одинаковый сид + одинаковые команды = одинаковый мир. Нужен для сервера, тестов, реплеев |
| **Данные отдельно от кода** (`game/src/data/`) | Баланс правится в таблицах данных, без переписывания логики |
| **Состояние — простой сериализуемый объект** | Сохранение = `JSON.stringify(state)`; позже — на сервер |
| **UI только читает состояние и шлёт команды** | Можно заменить UI/карту (Leaflet → Three.js) без касания экономики |
| **Без сборщика на старте** (ES-модули + Leaflet, лежит в `game/vendor/`) | Ноль зависимостей, запуск за секунду. Переход на Vite+TypeScript — на этапе 2 |

### Структура проекта
```
game/
  index.html            — точка входа
  styles.css
  package.json          — скрипты: start (локальный сервер), test
  tools/serve.mjs       — мини-сервер статики без зависимостей
  tools/headless.mjs    — прогон симуляции без UI (балансировка)
  src/
    main.js             — запуск, игровой цикл, сохранения
    data/               — города, районы, товары, бизнесы, события
    sim/                — ядро симуляции (без DOM!)
      rng.js            — детерминированный ГСЧ
      world.js          — генерация районов и участков
      state.js          — создание новой игры
      market.js         — товарный рынок, цены
      demand.js         — спрос покупателей (логит-модель)
      supply.js         — закупки, внутренние поставки, логистика
      tick.js           — шаг симуляции (день / месяц)
      commands.js       — команды игрока
      forecast.js       — прогноз «что если открыть здесь»
      events.js         — система событий
      ai.js             — ИИ-конкуренты
    ui/                 — карта, панели, HUD, форматирование
  tests/                — тесты симуляции (node --test)
```

## Этап 0 — Играбельный прототип экономики (текущий)

**Цель:** на реальной карте мира кликнуть на город → район → участок, открыть кофейню, обеспечить её поставками, нанять людей, поставить цены, увидеть прибыль/убыток, расширяться и строить вертикальную цепочку (плантация → обжарка → кофейня).

### 0.1 Ядро симуляции
- [x] Детерминированный ГСЧ (mulberry32) в состоянии.
- [x] Время: шаг = 1 игровой день; месячный расчёт (аренда, зарплаты, налоги, отчёт).
- [x] Генерация мира: 26 реальных городов + 11 сельхоз-регионов, районы 7 типов, ~900 участков.
- [x] Товары (10): кофе-зерно, обжаренный кофе, молоко, пшеница, мука, сахар, стаканы, выпечка, мясо, товары для магазина.
- [x] Мировой товарный рынок: мировая цена (случайное блуждание с возвратом к среднему) + влияние объёмов игрока + спред покупки/продажи.
- [x] Бизнесы (9): кофейня, пекарня, фастфуд-киоск, мини-маркет, обжарка кофе, мельница, кофейная плантация, молочная ферма, зерновая ферма. Склад-распределитель — на этапе 1.
- [x] Спрос покупателей: логит-модель по району (цена, качество, узнаваемость, видимость, конкуренты-ИИ, «не покупать»).
- [x] Мощность: персонал × производительность × уровень оборудования; недопродажи при нехватке мощности.
- [x] Запасы со средней себестоимостью; порча скоропорта.
- [x] Закупки: сначала со своих производств (с транспортом по расстоянию), затем на рынке.
- [x] Производство по рецептам; излишки продаются на рынок.
- [x] Маркетинг: бюджет → узнаваемость (убывающая отдача, затухание).
- [x] Финансы: касса, кредит, проценты, налог на прибыль по стране, месячные P&L по каждой точке и компании.
- [x] ИИ-конкуренты (фоновые): открываются/закрываются по прибыльности района.
- [x] События: заморозки в Бразилии, скачок цены молока, поломка, санинспекция, вирусный отзыв, конкурент рядом, повышение аренды.
- [x] Банкротство.

### 0.2 Интерфейс (2D, без 3D)
- [x] Карта Leaflet с тайлами OpenStreetMap.
- [x] 35 иконок в стиле low-poly (товары, бизнесы, районы, интерфейс), сгенерированы через OpenRouter — `game/tools/icons/`.
- [x] Иконки городов и регионов (эмодзи), при приближении — районы (цветные круги) и участки (иконки).
- [x] Панель участка: параметры + список «что можно открыть» с прогнозом выручки/прибыли/окупаемости.
- [x] Панель бизнеса: KPI, цены, персонал, маркетинг, запасы, апгрейд, закрытие, P&L.
- [x] Вкладки: «Мои бизнесы», «Рынок», «Финансы», «Новости».
- [x] HUD: деньги, дата, скорость (пауза/×1/×2/×4), прибыль за месяц.
- [x] Сохранение/загрузка в localStorage, новая игра.

### 0.3 Инструменты
- [x] Тесты симуляции (`npm test`): детерминизм, сохранение денег, работа цепочки поставок.
- [x] Headless-прогон (`npm run headless`) — 5 лет симуляции с ботом, вывод ключевых показателей.

**Критерий готовности этапа 0:** путь «1 кофейня → 5 кофеен → своя обжарка → своя плантация» интересно играть 30–40 минут; экономика не взрывается за 10 игровых лет в headless-прогоне.

## Этап 1 — Глубина экономики (4–6 недель)

1. **Контракты с ИИ-поставщиками и покупателями:** фиксированная цена, объём, срок, штрафы. Окно предложения/контрпредложения.
2. **Региональные рынки** вместо одного мирового: Европа, Северная Америка, Латинская Америка, Азия и т.д.; импорт/экспорт с пошлинами и фрахтом.
3. **Логистика как сущность:** грузы в пути с временем доставки, склады, собственные грузовики.
4. **Персонал глубже:** рынок труда города, зарплаты от спроса/предложения, мораль, управляющие (снимают «очки внимания»).
5. **Бренды:** несколько брендов, узнаваемость на уровне города/страны, сеть даёт общий бренд.
6. **Тир II:** ресторан, супермаркет, автосервис, грузоперевозки, IT-студия, рекламное агентство, ферма-животноводство, мясокомбинат, молокозавод, завод упаковки.
7. **Покупка недвижимости и девелопмент** (базово).
8. **Макроэкономика v1:** инфляция, ставка ЦБ, циклы по странам, валютные курсы.
9. **Отчёты:** графики истории (выручка, прибыль, цены) — Chart.js/uPlot.
10. **Обучение:** кампания «Первая чашка» (пошаговые задачи).

**Критерий:** внешние тестеры играют 1+ час без подсказок.

## Этап 2 — Переход на TypeScript + Vite, сервер (3–4 недели)

1. Миграция `src/sim` на TypeScript (типы товаров, команд, состояния).
2. Vite для клиента; React для панелей (по мере роста UI).
3. **Игровой сервер** (Node.js + WebSocket, затем Colyseus): комнаты, авторитетная симуляция, приём команд, рассылка состояния.
4. Разделение состояния на публичное/приватное (туман войны).
5. Деньги в целых центах; версия формата сохранений и миграции.

## Этап 3 — Мультиплеер (6–8 недель)

1. **Лобби по ссылке**, 2–4 игрока, выбор режима и настроек.
2. **Кооператив «Холдинг»:** общая компания, роли (CEO/CFO/COO/CMO/CTO), бюджеты, голосования, пинги на карте, чат.
3. **PvP «Свободный рынок»:** общий мир, конкуренция в районах, Индекс Империи, условия победы.
4. **Торговля между игроками:** окно сделки, контракты поставок, займы, продажа бизнесов.
5. Реконнект, ИИ-автопилот за отключившегося, сохранение сессий на сервере.

## Этап 4 — Корпоративный уровень (6–8 недель)

1. Тир III–IV: пищевые фабрики, сети/франшиза, логистическая компания, банк, нефтегаз, НПЗ, электроника, SaaS, энергетика.
2. Биржа: акции ИИ-корпораций и игроков, IPO, враждебные поглощения, совет директоров.
3. R&D и дерево технологий.
4. Государство: законы, лицензии, лоббирование, антимонополия.
5. ИИ-корпорации с архетипами и переговорами.
6. Директор событий: 100+ событий.

## Этап 5 — 3D и полировка (8–12 недель)

1. Three.js-глобус вместо Leaflet на уровне «мир/страна» (слой отображения подменяется, логика не меняется).
2. Процедурные 3D-районы, инстансинг, LOD.
3. Звук, музыка, анимации, онбординг, локализация.
4. Режимы «Рецессия», «Блиц», рейтинг.

## Этап 6 — Релиз и пострелиз
- Открытая бета → 1.0 → Steam-обёртка (Tauri) → моддинг → постоянный мир.

## Процесс разработки
- Каждая фича: данные → симуляция → тест → UI.
- После каждого изменения экономики — headless-прогон 10 лет: нет ли гиперинфляции, отрицательных запасов, «вечного двигателя».
- Баланс-цифры только в `src/data/`.
- Еженедельный плейтест (даже соло) с заметками «где было скучно / непонятно».

## Как запустить прототип
```bash
cd game
npm start          # http://localhost:8080
npm test           # тесты симуляции
npm run headless   # прогон 5 лет без UI
```
Зависимостей устанавливать не нужно (нужен Node.js 18+). Leaflet лежит в `game/vendor/`, подложка карты (тайлы OpenStreetMap) грузится из интернета.
